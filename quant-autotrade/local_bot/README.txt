자동 손절·익절 프로그램 (매수 기능 없음)
=========================================

흐름
  1) 블로그 차트검색에서 종목 상세를 열고 "자동매매 감시 추가"를 누른다(또는 자동매매 화면에서 종목코드 입력).
  2) 매수는 직접 한다(증권앱). 이 프로그램에는 매수 기능이 없다.
  3) 프로그램이 30초마다 키움 잔고를 읽어, "감시 종목"의 보유분만 규칙에 따라 시장가로 매도한다.
     감시 목록에 없는 보유 종목은 절대 건드리지 않는다.

규칙 (수익률 = 현재가 / 매입단가 - 1)
  - -3% 이하            -> 손절
  - +5% 이상            -> 즉시 익절
  - 한 번 +3% 이상을 넘겼다가 +3% 아래로 내려오면 -> 익절(수익 보호)
  값은 config.json 으로 바꾼다. 예) {"stop_loss_pct": 3, "take_profit_floor_pct": 3, "take_profit_cap_pct": 5}

안전장치
  - 실제 매도 주문은 .env 의 LIVE_SELL=true 일 때만 나간다. 비어 있으면(기본) "이 주문을 냈을 것"이라고 DRY_SELL 로 기록만 한다.
  - 같은 종목 재주문은 5분 대기, 종목당 하루 3회·전체 하루 10건까지. 한도에 닿으면 CRITICAL 로그를 남기고 멈춘다.
  - 폴더에 STOP 파일이 있거나 화면의 정지 버튼을 누르면 모든 판단이 멈춘다.
  - 잔고 조회가 3번 연속 실패하면 CRITICAL 로그(손절·익절 판단을 못 하는 상태).
  - 장 시간(평일 09:00~15:20)에만 동작한다.

처음 한 번
  1) .env.example 을 복사해 .env 로 만들고 KIWOOM_APPKEY, KIWOOM_SECRETKEY 를 직접 입력한다. (채팅·문서·코드에 붙여 넣지 말 것)
  2) 점검(읽기 전용, 주문 없음):  python main.py --check
     -> 토큰 발급과 잔고 조회가 되는지, 응답 형식이 맞는지 확인한다. 안 되면 출력된 응답 키를 알려 주면 필드명을 맞춘다.
  3) 처음에는 LIVE_SELL 을 비워 둔 채(기록만) 하루 정도 돌려 DRY_SELL 기록이 맞는지 본다.
  4) 확인되면 .env 에 LIVE_SELL=true 를 넣고 프로그램을 다시 시작한다.
  ※ 매도 주문(kt10001)·잔고(kt00018) 필드명은 공식 규격 기준이며 이 저장소에서 실호출 검증 전이다.
     모의투자로 먼저 확인하려면 .env 에 KIWOOM_BASE_URL=https://mockapi.kiwoom.com (모의 키)를 넣고 같은 순서로 확인한다.

실행: run.bat 더블클릭 (또는 python main.py). 창을 닫으면 멈춘다. 키움에 등록한 IP(이 PC의 공인 IP)에서만 접속된다.

화면(블로그 "자동매매")
  - 이 PC의 로컬 서버(127.0.0.1:8765)만 읽는다. 폴더의 .token 파일 내용을 화면의 "접속 토큰" 칸에 한 번 붙여 넣으면 이 브라우저에 저장된다.
  - 크롬이 "로컬 네트워크 접근"을 물으면 허용한다.

파일
  logs\autotrader-날짜.log (사람이 읽는 로그), autotrader.db (화면이 읽는 기록), .token (화면 접속 토큰), STOP (있으면 정지)
테스트(키 불필요): python -m unittest -v
