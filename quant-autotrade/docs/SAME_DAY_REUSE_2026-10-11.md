# 당일 자금 재투입 규칙과 모의 계좌 수정 (2026-10-11, 연구용·실주문 없음)

> 로컬 매도 봇의 −3%/+5% 규칙, `LIVE_SELL`, 실계좌 주문 기능, 기존 후보 생성 알고리즘, 장 마감 1회 검색 스케줄, 3개 청산 전략은 변경하지 않았다. 장중 신규 종목 자동 검색은 별도 과제로 남긴다.

## 1. 규칙

청산 뒤 다음 거래일까지 의무적으로 기다리는 규칙은 **없다**. 당일 재투입 가능 여부는 오직 "매도가 매수보다 먼저 체결됐음을 알 수 있는가"로 정한다. 일봉만으로 선후를 알 수 없으면 유리한 순서를 만들지 않고 두 가정을 나눠 보고한다.

| 규칙 | 구현 |
|---|---|
| 매도 체결이 확인된 대금만 현금 | 청산이 확정(`CLOSED`)된 뒤에만 현금 증가 |
| `OPEN`·`PENDING_EXIT`는 체결 전까지 한도·보유 수 점유 | 투자 한도 30%, 동시 5종목, 종목당 10% 계산에 포함 |
| 미체결 매도의 예상 대금은 현금 아님 | `PENDING_EXIT`의 대금은 계산하지 않음(테스트) |
| 증권사 실제 주문가능금액 초과 재매수 금지 | `allocation.entry_size(..., broker_cash=)` — 실거래 연결 시 실제 값을 넣는다(현재 모의는 미사용) |
| 시가 매수 | 같은 날 매도 대금을 쓰지 않는다(시가 시점의 선후를 알 수 없음) — 두 시나리오 모두 |
| **보수적 가정**(기본·공식 기록) | 그날 청산 대금은 다음 거래일부터 사용. 의무 규칙이 아니라 선후 불명 시의 가정 |
| **당일 재투입 시나리오** | 시가에 자금·자리가 없어 못 산 후보를 같은 날 **종가 +0.2%**에 매수(오후 매수). 신호 청산(다음 시가 체결)·장중 추적선 이탈 대금은 종가보다 앞서므로 사용 가능. 최대 보유일 **종가 청산 대금은 종가와 동시라 사용 불가** |

종가 재투입 후보는 청산 엔진을 그대로 쓰되 진입만 종가로 바꿔(`paper_exits.evaluate(..., entry_mode='close')`) 다음 봉부터 손절선·신호를 판정한다. 오후 매도 후 그날 오전 시가로 산 것처럼 계산하지 않는다.

## 2. 모의 계좌 계산 수정 (`candidate_gen.paper_account`·`paper_portfolios`)

- 이전: 청산이 끝난 거래만 계좌에 반영(실현 기준) → 미청산 포지션의 자금 점유·평가손익·MDD 누락.
- 이후: **날짜순 계좌 자산곡선** = 현금 + 보유 포지션을 **종가로 평가**한 값. 미청산 포지션은 한도를 점유하고 평가손익이 곡선에 반영된다. 누적수익률과 MDD는 이 곡선으로 계산한다.
- 평가에 쓸 확정 일봉은 `paper_bars` 테이블에 보관한다(진입·정산 때 저장, 확정 봉은 덮어쓰지 않음). 평가 종가가 없는 날이 있으면 `mddExact=False`, `mdd`는 비우고 `mddApprox`(참고값)만 낸다 — 정확한 MDD처럼 표시하지 않는다.
- 3개 청산 전략의 계좌는 계속 독립이다(합산 없음). 결과는 `status.json`의 `paperVariants`(기본 + `sameDay` 시나리오)와 `/api/research`로 나가고, 운영센터에는 "누적(평가)·MDD·당일 재투입 시나리오" 열로 보인다.
- 연구 작업을 여러 번 실행해도 기록·봉·계좌 결과가 같다(멱등, 테스트).

## 3. 백테스트: 당일 재투입 여부에 따른 계좌 수익률 차이

같은 신호·진입·비용·한도(동시 5·종목당 10%·투자 30%)에서 모의 계좌와 **같은 코드**(`account_sim.py`, `paper_exits.py`)로 계산했다(`backtest/reuse_study.py`, 국내 234종목 일봉 2022-04~2026-10, 생존편향 있음, 평가 종가 결측일은 직전 종가 이월, 시점 기준 종목 제외 적용).

눌림목, 누적 / MDD (보수적 가정 → 당일 재투입 시나리오)

| 청산 전략 | 보수적 | 당일 재투입 | 재투입 매수 |
|---|---|---|---|
| `trail_atr` | +66.8% / −12.6% | +82.7% / −11.5% | 66건 |
| `atr_close` | +42.9% / −11.7% | +25.6% / −13.4% | 74건 |
| `dead35` | +10.4% / −13.0% | +40.3% / −14.2% | 118건 |

이동평균 구름 돌파: `trail_atr` +22.7%/−17.8% → +24.7%/−11.9%, `atr_close` +39.4%/−7.1% → +22.4%/−7.5%, `dead35` −1.0%/−18.8% → +0.9%/−20.2%. 그 외 검색기와 무작위 진입 대조군은 방향이 엇갈린다(`reuse.json`).

**결과의 불안정성**: 같은 점수끼리의 매수 순서(동점 처리)만 바꿔도 결과가 크게 움직인다. 눌림목을 동점 순서 8가지 무작위로 돌린 범위:

| 청산 전략 | 보수적(8회 범위) | 당일 재투입(8회 범위) | 방향 |
|---|---|---|---|
| `trail_atr` | +70% ~ +86% | +84% ~ +113% | 8회 중 대부분 재투입이 높음(평균 약 +17%p) |
| `atr_close` | +40% ~ +57% | +22% ~ +33% | 8회 모두 재투입이 낮음(평균 약 −19%p) |
| `dead35` | +7% ~ +22% | +37% ~ +46% | 8회 모두 재투입이 높음(평균 약 +26%p) |

해석
- 당일 재투입이 **일관되게 이득이라는 근거는 없다**. 전략마다 방향이 다르다(`dead35`·`trail_atr`는 증가, `atr_close`는 감소). 재투입은 거래 수와 노출을 늘리고, 종가 매수는 시가 진입과 가격이 달라 서로 다른 거래가 선택되기 때문이다.
- 동점 순서만으로 한 설정 안에서 ±7~10%p가 움직이므로, 전략 간·시나리오 간의 작은 차이는 우연일 수 있다. 방향이 8회 모두 같았던 `atr_close`(감소)와 `dead35`(증가)만 시나리오 효과로 볼 여지가 있다.
- 이 수치는 이전 보고서(`TREND_EXIT_STUDY`)의 포트폴리오 수치와 다르다(예: `dead35` +21.5% → 보수적 +10.4%). 날짜 기준 청산·미청산 평가·동점 처리 방식이 달라졌고, 위 동점 순서 범위(+7~22%)가 보여 주듯 원래 결과가 순서에 민감하다는 뜻이다.
- 따라서 모의운영에서는 **보수적 가정을 공식 기록**으로 쓰고 당일 재투입은 참고 시나리오로 병기한다. 실제 체결 선후·호가·잔고(증권사 주문가능금액)는 모의 데이터로 검증할 수 없다.

## 4. 테스트 (`research/test_paper_accounts.py` 13건 등)

필수 6개 상황: ① 미청산 3종목이 한도 30%를 모두 사용 ② 오전 손절 후 같은 날 새 종목 매수 ③ 매도 체결 전 대금 사용 금지(`PENDING_EXIT`) ④ 매수 시점보다 늦게 체결된 매도 대금 소급 사용 금지(종가 청산·다음 날 청산) ⑤ 보유 종목 평가손실로 MDD 발생(−1.0%, 실현 기준이면 −0.8%로 보였을 값) ⑥ 연구 작업 반복 실행 시 기록·수익률 중복 없음. 추가: 주문가능금액 상한, 평가 종가 없을 때 `mddExact=False`, 시가 매수에 같은 날 매도 대금 사용 금지, 종가 진입 엔진(다음 봉부터 청산).
