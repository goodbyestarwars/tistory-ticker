# 수급 흔적 차트 개편 — 2026-10-19

상태: 작업 브랜치 `feature/chart-supply-traces`에서 구현 후 사용자 배포 승인. master 반영 및 GitHub Pages 자동 배포 대상.
차트검색과 종목분석의 공통 엔진에 적용했다. 검색기·자동매매·실계좌·서버·스킨 파일은 수정하지 않았다.

## 판정식

| 표시 | 계산식 / 확인 시점 |
|---|---|
| 주황 ● 거래량 급증 | `V[t] / mean(V[t-20:t]) >= 3`. 당일 제외 직전 20봉 모두 유효한 거래량 필요. 0은 포함하며 평균이 0이면 미판정. 양봉·음봉·거래대금 하한 제한 없음. |
| 보라 ■ 장기선 공방 | 유효한 연속 112·224·448봉 종가의 단순이동평균(SMA). `d=(C/MA-1)×100`. `abs(d)<=2%` 범위에 처음 들어오면 접근. 확인된 아래쪽 상태에서 `d>=1%`면 돌파, 위쪽 상태에서 `d<=-1%`면 이탈. 중간 ±1%에서는 이전 상태를 유지하여 흔들림에 따른 반복 마커를 줄인다. |
| 장기선 회복(■ 내부) | 확인된 이탈 뒤 20봉 이내에 위쪽 상태로 전환하면서 종가가 이탈일 MA 값 이상이면 회복, 그 외 아래→위 전환은 돌파. 같은 봉에서 접근보다 돌파·이탈·회복 우선. |
| 빨강 ▲ 회복 확인 | 급증봉의 `윗꼬리=(H-max(O,C))/(H-L) >= 40%`이면 추적 시작. 이후 최대 20봉 동안 모든 저가가 기준봉 저가의 98% 이상이고, 종가가 기준봉 고가를 처음 초과한 날 표시. 기준봉 당일에는 회복으로 표시하지 않는다. 저점 훼손·유효하지 않은 OHLC·기간 만료 시 해당 추적 종료. |

장기선 초기 상태: 해당 기간의 데이터가 처음 확보될 때 방향 기준만 설정한다. 초기 ±1% 중립 범위에서는 `C<=MA`를 아래, `C>MA`를 위로 초기화한다. 최초 확보 자체를 돌파로 간주하지 않는다. 접근 범위를 벗어났다 재진입하면 새로운 접근이 가능하다. 기간은 달력일이 아니라 입력 일봉 수 기준이다.

윗꼬리 기준은 긴 윗꼬리 및 역망치 형태를 함께 관찰하는 단순 기준이며, 별도 몸통 크기 제한은 없다. 장기선 ±2%/±1%, 추적 20봉/저점 허용 2%는 이번 표시 기능의 명시적 기준이다. 수익성이 검증된 최적 조건이라는 뜻이 아니다.

## 표시·데이터 처리

- 한 날짜에 유형별 최대 한 마커. 여러 장기선/기준봉의 조건은 같은 유형 안에 모으고, 십자선 툴팁에는 모두 제공한다.
- 세 유형이 겹쳐도 서로 덮어쓰지 않는다. 기존 추세·이벤트와 한 마커 플러그인으로 합친다. 재렌더/끄기 시 툴팁 구독을 해제한다.
- 툴팁: 직전20일 대비 배수, 종가×거래량으로 추산한 거래대금, 양봉/음봉/보합, 고저 범위 대비 윗꼬리 비율, 장기선 값/거리/동작, 회복의 기준일·경과봉·가격을 표시한다.
- 실제 거래대금은 OHLCV만으로 알 수 없어 대용값이라고 표시한다. 외국인·기관 순매수 또는 실제 세력 매집을 뜻하지 않는다.
- 주봉·월봉·분봉 및 미국 종목에서는 수급 흔적을 표시하지 않는다. 기존 토글 체크는 유지하고 국내 일봉 전용 안내를 제공한다. 종목분석은 기존 국내 일봉 화면이다.
- MA 기간이 부족하거나 OHLC가 유효하지 않으면 해당 MA 판정을 생략한다. 다른 기간/거래량 판정까지 막지 않는다. 거래량은 21봉부터 독립 판정 가능하다. 입력에 누락된 거래일 자체는 OHLCV만으로 확인할 수 없다.
- 미래 봉을 읽지 않으며, 회복은 발생일만 표시한다. 진행 중 일봉은 종가 확정 전 바뀔 수 있다고 툴팁에 명시했다.
- PC 마우스 이동, 모바일 터치 길게 누르기로 툴팁 확인. 툴팁은 컨테이너 및 화면 아래 경계를 지키고 긴 내용은 내부 스크롤한다. 확대를 축소하면 인접 날짜 마커 글자는 조밀해질 수 있으며 확대/툴팁으로 개별 정보를 확인한다.
