# 웹 주문(계좌 현황 2단계) 설계 — 2026-11-27 (구현됨, 기본 꺼짐)

목표: `/page/auto-trader` 계좌 현황에서 HTS 없이 매수·매도·취소. 구조는 `화면 → 서버(/autotrader/command) → 제어 에이전트(요청 파일) → 봇(주문 잠금 안에서 실행) → 결과(MANUAL_RESULT·텔레그램)`이며 기존 수동 매도(`manual_ops`, 2026-11-19 승인)를 확장한다. 제어 에이전트는 계속 브로커를 호출하지 않는다.

## 기존 경로에서 확인한 사실 (autotrader-private main, 2026-11-27)
- 수동 매도는 `manual_ops.write_request`(에이전트) → `bot.process_manual`(봇) → `order_guard.order_lock` + `can_order`(09:00~14:00, MANUAL_STOP 없음) + `LIVE_SELL` + UNKNOWN 장부 없음 + 잔고·미체결 확인을 거친다. `MANUAL_OPS_ENABLED=1`일 때만 capability가 올라간다.
- **봇이 쓰는 클라이언트는 `kiwoom.KiwoomClient`이며 `buy_limit`·`cancel_order`가 없다**(엔진용 `live_kiwoom.KiwoomClient`에만 있음). 웹 매수·취소에는 봇 클라이언트 확장이 필요하다.
- 주문 장부(`live_orders.db intents`)에 BUY를 남기면 엔진이 자기 포지션으로 오인할 수 있다(수동 매도도 엔진 보유 종목은 전량만 허용). 수동 매수 처리 방식을 정해야 한다.
- 계좌 조회 연동(`ACCOUNT_VIEW.json`, PR #15)으로 화면은 증권사 기준 잔고·미체결·주문가능금액을 이미 본다.

## 결정이 필요한 항목
1. **범위**: 매도(기존)만 화면에 연결 / + 지정가 매수 / + 미체결 취소. 권장: 매도 연결 → 취소 → 지정가 매수 순 단계 반영.
2. **매수 가드**: 종목당·1회 한도 금액, 시장가 매수 금지(지정가만), 인버스·레버리지·현금성 ETF 제외 유지, 엔진의 `HOLD_BUY`·하락장 매수 제어와의 관계(수동 매수는 적용 여부).
3. **장부**: 수동 매수를 `intents`에 `MANUAL_BUY`로 남기되 엔진 포지션 생성은 막는 방식(권장) vs 장부 밖 기록.
4. **시간**: 현재 `can_order`는 14:00 이후 전부 차단. 수동 주문도 동일 적용(권장) vs 별도 시간.
5. **확인 절차**: 화면 2단 확인(종목·수량·금액 재입력 모달) + 텔레그램 접수/체결 알림.

## 안전 원칙(고정)
- 기본 꺼짐: 새 capability(`manual-buy-v1`, `manual-cancel-v1`)는 `MANUAL_OPS_ENABLED=1`일 때만. 서버 화이트리스트·인자 검증·Origin·관리자 세션 필수.
- 취소·재시도 자동화 없음, 실패는 UNKNOWN 기록 후 사용자 확인. 계좌·주문번호는 화면·로그에 노출하지 않는다.
- 병합·재시작·`.env` 활성화는 각각 구체적 사용자 승인 후, 장외 검증 순서로 진행한다.

## 확정 결정 (사용자 지시 2026-11-27) 와 구현
- 한도는 **주문가능금액**(예수금 기준) — 고정 한도 없음. 서버(화면 입력 시점·계좌 조회 신선도 필요)와 에이전트(실행 직전 `cash_available`)가 각각 확인.
- **자동매매는 기존 규칙 그대로**(`order_guard.can_order`, 14:00). **수동 주문은 평일 09:00~15:00**(`can_manual_order`). 자동매매 정지(MANUAL_STOP)는 수동 주문을 막지 않고 긴급 `STOP` 파일은 모두 막는다.
- 범위: 지정가 매수(시장가 매수 없음)·매도(장부 밖 증권사 보유 종목 포함, 매도가능 수량 이내)·종목 단위 미체결 전부 취소.
- 장부: 수동 매수는 `intents.side='MBUY'`(엔진의 BUY 기준 무영향). 증권사 명확 거부는 `REJECTED`(UNKNOWN 아님 → 엔진 정지 안 함), 응답 불명만 UNKNOWN.
- 확인: 종목코드 재입력 모달. 켜는 법: 에이전트 `.env`의 `MANUAL_OPS_ENABLED=1`(+ 매수는 `MANUAL_BUY_ENABLED=1`) — 켜기·runner/봇 재시작은 별도 승인.
- 텔레그램 알림: 이번 범위 밖(봇 이벤트 `MANUAL_OP`는 기존대로 기록). 미구현.
