## 사용자 흐름

종목 검색 결과에서 선택 → 공시 및 모형 자동 분석 → 기본 가치와 보수적/기본/낙관적 시나리오 → 최근 확인가격과 비교 → 과거 5년 현금흐름 → 주요 가정 → 기본 접힌 상세 근거 및 직접 조정. 숫자 입력이나 검토 체크박스는 자동 분석의 필수 조건이 아니다. 중요 누락자료는 체크박스로 무시할 수 없다. 직접 입력 모드와 공시 원본 복원·기업별 수정본은 유지한다.

자동 결과는 모두 `추정 포함 계산`이다. 미래 FCFF·할인율·성장률 등은 실제 공시가 아니므로 `공시 기반 계산`이라고 오인시키지 않는다. 상태 체계에는 공시만으로 계산하는 확장 영역을 두되 현재 집계의 disclosureOnly는 0이다. 자료 부족, 비양수 FCFF, 금융업/스팩/지주회사/우선주는 `자동 평가 불가` 사유와 확보된 공시/추세를 표시한다. 상대가치 숫자로 임의 대체하지 않는다.

## 실행 경계와 파일

- DART 수집·정규화: `scripts/build_dcf_data.py`, `scripts/dcf_normalize.py`. 기존 dart_client는 PC/Actions에서만 재사용, VM 실행 코드는 변경하지 않는다.
- 검색·기업 파일·가격·보완자료·집계는 `dcf-data/`. VM 재시작/재스캔 감시의 `data/` 밖에 둔다.
- 회사별 원본: `companies/{code}.js`, 출처/접수번호/단위/원금액/검증 상태 보존. 모든 정규화 후보 및 중복 rawRows 보존, 무관 계정은 용량 절약을 위해 제외.
- 공식 원문 보완: `supplements/{code}.js`. 현재 삼성전자·SK하이닉스. 연도·연결기준·최신 접수번호·매출/영업이익 fingerprint가 일치해야 적용. 미래 결산이나 정정 공시에서 불일치하면 이전 보완값으로 평가하지 않는다. 원본 기업 파일을 덮어쓰지 않는다.
- `quotes.js`: 기존 사이트 공급자(네이버)의 명시적인 NXT 거래시각/최근 가격. `build_dcf_quotes.py`가 PC/Actions에서 40종목 배치·5초 제한·최대6시간마다 갱신. 수집 시각을 거래시각이나 KRX 종가로 꾸미지 않는다.
- `dcf_coverage.js`: 공시 파일 확보와 자동 평가 가능성을 별도 집계. `resume_dcf_collection.py`: 재시도 가능한 미확보 기업이 있고 일일 한도가 남을 때만 다음 bounded Actions를 하나 예약. 이미 대기 실행이 있으면 중복 예약하지 않는다.
- `js/dcf-core.js`: 원본과 분리된 자동 모형·기존 수동 산식/상태. `js/dcf.js`: 결과 우선 UI·검색·접힌 근거표·실시간 재계산. `css/dcf.css`: 범위 스타일/모바일 내부 표 스크롤.

브라우저는 정적 JSON 부분을 파싱하며 임의 코드를 실행하지 않는다. 종목 변경/모드 변경 때 취소·15초 시간 제한·응답 토큰으로 이전 기업 응답을 무시한다. VM/GAS/인증 API 요청·WebSocket·추가 타이머·상시 프로세스·DB 쓰기 없음. 기존 툴팁의 `ticker_cache_{code}` 세션 캐시는 추가 요청 없이 5분 내 조회가격을 재사용하며 거래시각 미확보를 명시한다. 출처/시각이 있는 정적 가격은 10일 초과/미래 시각 거부. 가격 미확보는 주당 가치 계산을 막지 않지만 할인·할증률은 표시하지 않는다.

## 공시와 자동 추정 규칙

공시 규격 schemaVersion1, KRW 원금액, 연결 CFS 우선/보고서 존재 확인 후 OFS. 최신 완료5개 사업연도와 운전자본 선행1년. 연간11011 당기·최신 접수번호만 사용, 분기 누적/비교연도를 원본처럼 사용하지 않는다. 동일 연결/별도 기준 유지. 누락/중복/세부 부문/외화/단위 미확인은 null, 실제0과 구별. 비12월 결산은 현재 완료 달력 연도에 맞지 않으면 자동평가 제한.

자동 모형에 review 후보를 쓰려면 보고서 접수번호·KRW·정확한 계정명을 검증한다. 비표준 이름을 임의 승인하지 않으며 원본의 review 상태는 보존한다. 영업운전자본은 매출채권+재고−매입채무 대용치로 표시. ΔNWC는 동일 기준 전년 차이. 기타 영업자산/부채·환율/비현금 변화까지 완전히 제거한 값은 아니다.

D&A는 검증된 합계 또는 감가상각/무형상각 양쪽 계정. CAPEX는 유형/무형 취득 지출의 양수 합계이며 처분액과 상계하지 않는다. 필수값을 0이나 OCF−CAPEX로 대체하지 않는다. OCF−CAPEX는 별도 비교 추세이다. 공식 주석으로 리스 금융부채를 포함한 경우 신규 리스 사용권자산 취득도 모형 CAPEX에 반영해 D&A·부채 처리와 맞춘다. 현금 CAPEX 원본은 유지한다.

정상 세율 = 수익 발생 연도 법인세비용/세전이익 중 0~100%의 유효한 비율이3개 이상이면 중앙값을15~30%로 제한. 부족하면 명시적인25% 모형 가정. 부의 세금혜택·비정상 비율을 영구 세율로 쓰지 않는다. 사용자는 별도 모형 정상 세율을 조정할 수 있다.

FCFF = EBIT×(1−정상세율)+D&A−모형CAPEX−ΔNWC. 최근3년 핵심값이 모두 있고 최신값 및3년 중앙값이 양수여야 자동 미래 추정. 정상화 기준 FCFF = 최신값과 최근3년 중앙값의 평균. 음수기업을 양수 회복으로 임의 전환하지 않는다.

성장률: 매출/양수 영업이익/연속 양수 FCFF 전년 증가율을 각각±20%로 제한, 유효 변화가2개 이상인 계열의 중앙값을 모아 중앙값×50%, 최종−3~10%. 과거 증가율을 그대로 연장하지 않는다. 회계상 일회성 항목을 완전히 제거했다고 주장하지 않는다. 미래5년은 정상화 FCFF에서 해당 성장률로 추정.

WACC 구성 측정자료(무위험수익률·프리미엄·베타·부채비용·시가 자본구조)는 미확보. 기본10%는 측정 WACC가 아닌 사전 정의 시나리오 할인율. 영구성장률 기본2%. 보수적은 할인율+2%p/영구성장률−1%p/예측성장률−2%p/기준 현금흐름×85%, 낙관적은−1%p/+0.5%p/+2%p/×115%. 사용자 지정 미래 현금흐름은 유지하면서 할인율·영구성장률 민감도를 보여준다. WACC>영구성장률, 주식수>0, 최종FCFF>0 검증.

지분가치 = 5년 FCFF 할인합계 + 영구가치 할인 − (리스 포함 차입금−현금+비지배지분 장부금액). 투자자산은 별도 가산하지 않는 보수적 근사, 비지배지분은 시장가치 대신 장부금액 가정. 차입금 일부 누락이나 비지배지분 미확보를0으로 처리하지 않는다. 주식수 발행−자기=유통 대조 및 동일 접수번호 확인. 종류주식이 있으면 검증한 배분자료 없이는 차단. 삼성은 보통/우선 경제가치를 동일 배분하고 두 종류 유통 합계로 나누는 명시적인 가정이며 의결권/추가배당/향후희석은 미반영.
