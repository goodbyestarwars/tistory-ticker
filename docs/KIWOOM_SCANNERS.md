# 키움 영웅문 조건검색식 보관 기록

사용자가 제공한 과거 조건검색식을 다시 찾을 수 있도록 보관한다. 아래 문구와 논리식은 원문의 기호, 수치, 단위, 순서를 유지한다. 현재 영웅문에서의 사용 여부, 실제 사용 시간대, 실시간 검색 결과와 투자 성과는 확인되지 않았다.

## 시초가 단타 (과거 기록)

| 지표 | 내용 |
|---|---|
| A | [일]0봉전 일목균형표(9,26,52) 5봉이내 주가 선행스팬 1 상향돌파후 지속 |
| G | [일]0봉전 일목균형표(9,26,52) 5봉이내 주가 선행스팬 2 상향돌파후 지속 |
| H | 체결강도 100.0%이상 999999%이하 |
| L | [일]0봉전 MACD(12,26) 0선 이상 |
| M | [일]0봉전 Bollinger Band(40,2) 종가가 상한선 상향돌파 |
| N | 액면가 1 이상 999999 이하 |
| P | [일]1봉전 5봉 평균거래량 100000이상 999999999이하 |
| R | 5일 평균거래대금(단위:백만) 500이상 1000이하 (금일제외) |
| S | [일]거래량:100000이상 999999999이하 |

```text
(A or G) and H and L and M and N and (P or R) and S
```

## 도장깨기 (과거 기록)

| 지표 | 내용 |
|---|---|
| C | 주가이평배열(4):[일]1봉전 종가 5이평 < 20이평 < 112이평 < 224이평 |
| I | 거래량비율:[일]5봉 평균(0봉전)거래량대비 동일주기 0봉전 150%이상 |
| J | 주가이평추세:[일]1봉전 (종가 20)이평 상승추세유지 1회 이상 |
| D | 주가이평추세:[일]1봉전 (종가 5)이평 상승추세유지 1회 이상 |
| K | 주가이평추세:[일]1봉전 (종가 112)이평 상승추세유지 1회 이상 |
| L | 주가이평추세:[일]1봉전 (종가 224)이평 상승추세유지 1회 이상 |
| E | 이평이격도:[일]1봉전(종가 5, 종가 20) 5%이내 근접 1회이상 |
| G | 이평이격도:[일]1봉전(종가 112, 종가 224) 5%이내 근접 1회이상 |
| F | 이평이격도:[일]1봉전(종가 20, 종가 112) 5%이내 근접 1회이상 |
| H | 상세이평비교:[일]0봉전 지수(종가 5 )이평이 지수(종가 20)이평을 5봉이내 2 이내 근접 1회 이상 |
| M | 상세이평비교:[일]0봉전 지수(종가 20 )이평이 지수(종가 60)이평을 5봉이내 3 이내 근접 1회 이상 |
| N | 상세이평비교:[일]0봉전 지수(종가 60 )이평이 지수(종가 120)이평을 5봉이내 3 이내 근접 1회 이상 |
| O | 상세이평비교:[일]0봉전 지수(종가 120 )이평이 지수(종가 240)이평을 5봉이내 3 이내 근접 1회 이상 |

```text
C and I and (J or D or K or L) and (E or G or F) and (H or M or N or O)
```

원본 대화의 도장깨기 표는 H 이하가 잘려 있었으므로 H·M·N·O는 사용자가 이번 보관 요청에 적은 문구를 따른다. 실사용 효과와 사용 시간대는 검증하지 않았다.
