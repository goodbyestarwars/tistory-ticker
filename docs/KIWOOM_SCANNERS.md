# 키움 영웅문 조건검색식 보관 기록

사용자가 제공한 과거 조건검색식을 다시 찾을 수 있도록 보관한다. 아래 문구와 논리식은 원문의 기호, 수치, 단위, 순서를 유지한다. 사용자 설명에 따르면 키움은 조건검색식에 사용 시간대를 저장하지 않는다. 따라서 이 기록에는 사용 시간대가 없다. 조건 문구의 [일]·[1분] 등은 지표 주기이며 사용 시간대가 아니다. 현재 영웅문에서의 사용 여부, 실시간 검색 결과와 투자 성과는 확인되지 않았다.

## 시초가 단타 (과거 기록)

| 지표 | 내용 |
|---|---|
| A | [일]0봉전 일목균형표(9,26,52) 5봉이내 주가 선행스팬 1 상향돌파후 지속 |
| G | [일]0봉전 일목균형표(9,26,52) 5봉이내 주가 선행스팬 2 상향돌파후 지속 |
| H | 체결강도 100.0%이상 999999%이하 |
| L | [일]0봉전 MACD(12,26) 0선 이상 |
| M | [일]0봉전 Bollinger Band(40,2) 종가가 상한선 상향돌파 |
| N | 액면가 1 이상 999999 이하 |
| P | [일]1봉전 5봉 평균거래량 100000이상 999999999이하 |
| R | 5일 평균거래대금(단위:백만) 500이상 1000이하 (금일제외) |
| S | [일]거래량:100000이상 999999999이하 |

```text
(A or G) and H and L and M and N and (P or R) and S
```

## 도장깨기 (과거 기록)

| 지표 | 내용 |
|---|---|
| C | 주가이평배열(4):[일]1봉전 종가 5이평 < 20이평 < 112이평 < 224이평 |
| I | 거래량비율:[일]5봉 평균(0봉전)거래량대비 동일주기 0봉전 150%이상 |
| J | 주가이평추세:[일]1봉전 (종가 20)이평 상승추세유지 1회 이상 |
| D | 주가이평추세:[일]1봉전 (종가 5)이평 상승추세유지 1회 이상 |
| K | 주가이평추세:[일]1봉전 (종가 112)이평 상승추세유지 1회 이상 |
| L | 주가이평추세:[일]1봉전 (종가 224)이평 상승추세유지 1회 이상 |
| E | 이평이격도:[일]1봉전(종가 5, 종가 20) 5%이내 근접 1회이상 |
| G | 이평이격도:[일]1봉전(종가 112, 종가 224) 5%이내 근접 1회이상 |
| F | 이평이격도:[일]1봉전(종가 20, 종가 112) 5%이내 근접 1회이상 |
| H | 상세이평비교:[일]0봉전 지수(종가 5 )이평이 지수(종가 20)이평을 5봉이내 2 이내 근접 1회 이상 |
| M | 상세이평비교:[일]0봉전 지수(종가 20 )이평이 지수(종가 60)이평을 5봉이내 3 이내 근접 1회 이상 |
| N | 상세이평비교:[일]0봉전 지수(종가 60 )이평이 지수(종가 120)이평을 5봉이내 3 이내 근접 1회 이상 |
| O | 상세이평비교:[일]0봉전 지수(종가 120 )이평이 지수(종가 240)이평을 5봉이내 3 이내 근접 1회 이상 |

```text
C and I and (J or D or K or L) and (E or G or F) and (H or M or N or O)
```

원본 대화의 도장깨기 표는 H 이하가 잘려 있었으므로 H·M·N·O는 사용자가 이번 보관 요청에 적은 문구를 따른다. 실사용 효과는 검증하지 않았다.

## 224일선 돌파 구름떼 돌파 (과거 기록)

| 지표 | 내용 |
|---|---|
| A | [일]0봉전 일목균형표(9,26,52) 선행스팬 1 > 선행스팬 2 |
| B | [일]0봉전 일목균형표(9,26,52) 1봉이내 주가 선행스팬 1 상향돌파후 지속 |
| C | [일]0봉전 일목균형표(9,26,52) 선행스팬 2 > 선행스팬 1 |
| D | [일]0봉전 일목균형표(9,26,52) 1봉이내 주가 선행스팬 2 상향돌파후 지속 |
| E | 주가등락률:[일]1봉전(중) 종가대비 0봉전 종가등락률 2%이상 |
| F | 주가이평돌파:[일]0봉전 (종가 1)이평 (종가 224)이평 골든크로스 |
| G | [일]거래량:100000이상 999999999이하 |

```text
(A and B) or (C and D) and E and F and G
```

논리식은 사용자가 제공한 괄호 위치와 연산 순서를 그대로 기록했다. 실사용 효과는 검증하지 않았다.

## 오돌이 전날 포착 (과거 기록)

| 지표 | 내용 |
|---|---|
| H | 주가이평배열(4):[일]0봉전 종가 5이평 <= 20이평 <= 60이평 <= 120이평 |
| I | 주가이평비교:[일]1봉전 (종가 1)이평 <= (종가 5)이평 1회이상 |
| J | 주가이평비교:[일]0봉전 (종가 1)이평 >= (종가 5)이평 1회이상 |
| K | [일]0봉전 LRS(종가,5) 1봉 연속상승 |
| L | 거래량비율:[일]5봉 평균(0봉전)거래량대비 동일주기 0봉전 100%이상 |
| N | 주가등락률:[일]1봉전(중) 종가대비 0봉전 종가등락률 5%이상 |

```text
H and I and J and K and L and N
```

사용자는 이름에 대해 "5일선을 돌린다 라는 의미 인듯"이라고 덧붙였다. 이는 사용자 해석으로만 보관하며 조건의 확정적 의미나 실사용 효과로 간주하지 않는다.

## 돌파검색기 (과거 기록)

| 지표 | 내용 |
|---|---|
| A | 신고가:[일]0봉전 종가가 20봉중 신고가 |
| B | 최고종가:[일]0봉전 종가가 20봉중 최고종가 |
| C | 기간내 거래량비율:[일]1봉전 19봉이내에서 전봉거래량대비 500%이상 1회 이상 |
| D | 전일 동시간대 대비 거래량 증감률 순위 상위 300 |
| E | 주가이평배열(3):[일]0봉전 20이평 < 60이평 < 120이평 |
| F | 시가총액:현재가기준 100십억원 이상 |
| G | [일]거래량:500000이상 999999999이하 |

```text
(A or B) and C and D and !E   and F and G
```

논리식의 `!E`와 공백을 포함해 사용자 제공 형태 그대로 기록했다. 실사용 효과는 검증하지 않았다.

## 역배열 바닥 줍기 (과거 기록)

| 지표 | 내용 |
|---|---|
| A | 주가이평비교(3):[일]0봉전 종가5<종가20,종가20<종가60,종가60<종가112 1회이상 |
| C | 주가이평비교:[일]0봉전 (종가 112)이평 < (종가 224)이평 1회이상 |
| B | 주가돌파:[일]1봉(전) 고가를 현재가가 상향돌파 |
| D | 거래량이평추세:[일]0봉전 5이평 상승추세유지 1회 이상 |
| G | [일]주기 일목균형표(9,26,52) 선행구간 최근 1기간내(중기값 범위내) 선행스팬1과 선행스팬2 근접률 10% 이내 |

```text
(A and C) and B and G
```

D는 제공된 조건 목록에 있으나 제공된 논리식에는 포함되지 않는다. 목록과 논리식을 수정하지 않고 각각 그대로 보관한다. 실사용 효과는 검증하지 않았다.
