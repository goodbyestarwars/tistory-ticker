## 3. 코드에서 알아두면 좋은 것 (이번 세션에서 파악)

- **홈 대시보드 조립 흐름**: `js/skin-main.js`의 `buildHomeDashboard` IIFE(약 1,300줄).
  홈(`/`)에서만 실행. 정적 마크업을 만들고 첫 글 카드 앞에 삽입한 뒤, 4개 홈 모듈
  (`home-weekly-report.js`/`home-widgets.js`/`home-realtime-table.js`/`home-economic-news.js`)을
  `Promise.all`로 병렬 지연 로드. `stock-calendar.js`는 홈 일정 카드용으로 +2초 뒤 로드.
- **공유 로더 패턴**: `window.HomeMarketBoard`(skin-main이 먼저 정의, home-realtime-table.js가
  같은 이름으로 자기 구현 덮어씀 - 둘 다 `window.__homeMarketBoardRequests` 풀·limit 40·
  30초 창을 공유해 호환). `window.EarningsCalendarFeed`(60초 TTL). 새 홈 위젯이 같은
  엔드포인트를 부를 땐 이 전역들을 우선 쓸 것.
- **죽은 코드지만 저장소에 남겨둔 파일** (롤백 대비, skin.html에서 로드 안 함):
  `js/investor-trend-widget.js`, `css/investor-trend-widget.css`,
  `js/sidebar-rank.js`, `css/sidebar-rank.css`,
  `js/quick-indices.js`(껍데기 - `fetchFutures`/`fetchMarket`만 실코드),
  `css/quick-indices.css`. 관련 계약 테스트(`test_ui_ia.py`)는 파일 내용을 검사하므로
  파일을 지우면 테스트가 깨진다. 정리하려면 테스트도 같이.
- **`--qi-height`**: 이제 `:root`에서 0px 기본. 참조하는 CSS는 모바일 padding calc
  한 곳(`style.css` `@media` 안)뿐. 리본을 되살릴 일이 있으면 `:root` 값을 양수로
  올리고 `quick-indices.js` `init()` 뒤 렌더 호출을 복구하면 됨.
- **`HOME_USE_SAMPLE_CHARTS`**: 레이아웃 작업 중 지수 카드 차트를 고정해야 하면 이 값을
  다시 `true`로만 바꾸면 됨(기구 유지). 테스트
  `test_home_index_charts_use_live_futures_data_with_sample_toggle_retained`가
  `= false`를 고정하고 있으니 같이 수정.
- **홈 지수 카드는 주말(휴장)에 안 뜬다**: `homeMarketSession()`이 `closed`면
  `loadHomeIndices()`가 즉시 return. 실데이터 차트 렌더는 평일에만 확인 가능.
- **`/market-board` 워머 포트**: `os.environ['PORT']` 또는 `APP_PORT`, 없으면 `8080`
  하드코딩(현재 `uvicorn main:app --port 8080`). 포트가 바뀌면 워머가 조용히 실패하고
  온디맨드 경로로 폴백(무해)하지만 워머 효과는 사라짐 - VM 실행 방식 바뀌면 확인.
- **KIS/키움 시장 판정**: `_economic_news_market()`(KST 시간대 기준, US 프리마켓 17:00~).
  워머는 이 함수가 반환하는 "지금 홈이 요청할 시장" 하나만 데운다. 다른 시장의 첫
  방문자는 콜드 미스 1회.
