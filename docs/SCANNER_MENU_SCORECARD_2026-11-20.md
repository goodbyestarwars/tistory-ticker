- KOSPI 60일선 위인 날만 사면 검증·시험 두 기간은 '살림' 조건(초과 +1%p 이상·PF 1.2 이상·100건 이상)을 넘었다(+1.88·PF 1.27 / +2.85·PF 1.25). 학습 기간(2021~2023 하락기) 초과가 -1.43%p라 기준의 마지막 조건(학습 초과 0 초과)에서 떨어졌다.
- 모든 날로는 검증 초과 +0.86%p로 +1%p에 못 미쳤다.
- 해석: 저점상승은 2024년 이후 상승장에서는 아무 종목보다 나았지만 2021~2023 하락기에는 더 나빴다. 주도주 조용한 눌림(7단계 전 exit-v1 학습 PF 0.76)과 같은 모습이다. 바닥 형성 메뉴(1단계 숨김 후보)보다 저점상승 단독이 낫다.
- 다음에 쓸 수 있는 것(새 기준을 정해 따로 검증해야 함): 'KOSPI 60일선 위 + 60일선 매도' 조합이 참고값에서 가장 좋았지만, 결과를 본 뒤 고른 조합이라 이 결과만으로 반영하지 않는다.
