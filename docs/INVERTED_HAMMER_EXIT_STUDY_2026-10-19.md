# 역망치 매집 · 224일선 위 세력 탈출 · 고점 무거래량 일봉 검증 (2026-10-19, 연구용, 도입 근거 없음)

사용자 가설(2026-10-19): (1) 역배열에서 나온 역망치가 이평선을 1:1 이상으로 뚫고 도로 빠지면 매집, (2) 같은 역망치가 224일선 위에서 나오면 탈출, (3) 저점에서 거래량이 터지고 고점에서 거래량이 안 터지면 세력 이탈이 없고 우상향이 이어진다.
자료: 네이버 일봉 2,618종목(2020-01~2026-10, 거래대금 30억 이상 종목일만). 코드 `scripts/research/inverted_hammer_study.py`, 결과 `research_data/inverted_hammer_2026-10-19/results.json`, 테스트 `test/test_inverted_hammer_study.py`(5).

## 사용자 정의의 숫자화(해석이므로 틀리면 알려 주세요)
- 역망치: 범위 2% 이상, 윗꼬리 >= 범위 60%, 아랫꼬리 <= 15%, 몸통 <= 30%(양·음봉 무관).
- 대량: 거래량 >= 직전 20일 평균 x 2.5. 고점 무거래량: 거래량 < 평균. 고점권: 종가 >= 250일 고가의 95%.
- 역배열: MA5 < MA20 < MA60 < MA120. 뚫고 빠짐(1:1): MA20·60·120 중 하나가 봉 범위 안에 있고 MA 위 길이 >= MA 아래 길이, 종가는 MA 아래.
- 성과: 다음 거래일 시가(+0.10%) 매수 -> N거래일 뒤 종가(-0.15%) 매도, 순수익은 0.7% 차감. **초과수익 = 같은 날짜 유동 종목 평균 총수익 대비**(날짜 묶음 t). 학습 2025-01 이전 / 검증 2025-01 이후.
- 탈출 패턴의 낮은 총수익은 '이후 하락'의 증거일 뿐 공매도 수익이 아니다(대차·비용 별도).

## 결과 요약
1. **고점에서 거래량이 안 터지면 우상향** 가설은 **지지된다.** 고점권(250일 고가의 95% 이상, 54,868건) 중 거래량 평균 미만 20,426건: 20일 초과 +1.19%p(t 5.8), 60일 초과 +3.42%p(t 9.6), 학습 +3.22 / 검증 +3.96으로 두 기간 모두 양(+). 거래량이 평균~2.5배(보통)는 60일 +3.61%p로 비슷하다.
2. **고점에서 대량(>=2.5배)이 터지면 이 우위가 사라진다**(11,604건): 5일 -0.10%p, 20일 +0.47%p(t 1.2), 60일 +0.21%p(t 0.4), 검증 기간 60일 -3.12%p. 즉 "고점 대량 = 이탈 신호"의 방향이 맞다(하락이 아니라 우위 소멸).
3. **224일선 위 대량 역망치 = 탈출**도 방향은 맞다: 8,779건, 20일 초과 -1.67%p(t -6.0), 60일 -3.53%p(t -7.0), 학습·검증 모두 음(-). 224선보다 20% 이상 위면 60일 -4.17%p(4,023건). 다만 고점권 대량 일반(위 2)보다 크게 나쁘지는 않아 '역망치' 모양 자체의 추가 효과는 확인하지 못했다.
4. **역배열 역망치 매집은 확인되지 않았다**: 뚫고 빠짐(1:1) 1,986건 5일 -0.10%p(t -0.3), 20일 +0.50%p(t 1.0), 60일 -0.88%p(t -1.0), 검증 60일 -5.04%p. 뚫기 없는 경우(1,569건)가 20일 +1.13%p(t 1.0)로 약간 낫지만 모두 유의하지 않다. 총수익은 대부분 음수라 순수익은 비용을 넘지 못한다(20일 순수익 -1.5%).
5. 저점 대량(역망치 아님, 250일 범위 하위 20%): 20일 -1.28%p(t -4.7), 60일 -3.62%p(t -8.7) - 저점에서 거래량이 터져도 그 자체로는 상승 전조가 아니다(떨어지는 칼날 포함).

## 한계·미검증
- 고점권 우위에는 모멘텀 효과가 섞여 있다(거래량 조건을 빼도 고점권 전체가 60일 +2.7%p). 거래량 무거래량이 추가로 좋은 이유인지는 분리하지 못했다(보통 구간이 같은 수준).
- 정의의 숫자화는 해석이다(특히 1:1, 역배열 이평선 조합, 95% 고점권). 종가 확정 후 다음날 시가 진입 기준이며 장중 감지는 아니다.
- 생존편향: 네이버 현재 상장 종목 위주 일봉이라 상장폐지 종목이 빠졌을 수 있다. 수정주가 여부는 미확인.
- 연구용이며 기존 검색기·자동매매·실계좌 엔진은 변경하지 않았다.
