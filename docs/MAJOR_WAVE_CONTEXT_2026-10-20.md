# 대파동 보조 설명 통합 (2026-10-20)

## 채택 범위

별도 추세 체크박스·1/3/6/12개월 4개 상태 영역과 DOM 설치 함수를 제거했다. `chart-core.trendRegimes`의 기간별 종가 변화와 3봉 확인을 `majorWaveContext`에서 대파동 방향과 비교한다. 방향 일치, 불일치/3봉 확인 중, 6/12개월 역행, 중립, 자료 부족을 구분한다. 일/주/월은 기존 비교 간격을 그대로 쓰고 분봉에는 적용하지 않는다. 원 비교용 계산 API는 보존한다.

`auto-wave.js`는 바이트까지 변경하지 않았다. ATR14×8·실제 고저 극점·박스·중/소파동·확정 시점·신호를 보존하며 보조 설명만 통합한다. 기간 흐름으로 극점이나 확인 봉을 앞당기는 후보는 채택하지 않았다. 수익성 개선을 주장하지 않는다.

## 표시와 시점

- `파동 분석 > 대파동`: 선택한 확정 파동은 실선, 진행 중은 점선. 종전 상승 빨강/하락 파랑/횡보 회색/큰 박스 보라 회색 유지.
- 머리글에 `현재 자료로 재구성`과 선 의미를 표시한다. 중/소파동과 상위 윤곽 표시도 유지한다.
- 십자선은 날짜까지의 OHLCV 접두 구간을 재분석해 `당시 자료 기준`으로 안내한다. 오늘의 확정 정보를 과거 날짜에 소급하지 않는다.
- 현재 그림에서 해당 날짜를 덮는 영역이 있으면 `사후 재구성`으로 별도 표기한다. 실제 확정일과 확정 당시 기간 설명을 적으며 조회일 이후 확정은 `조회일에는 미확정`으로 명시한다.
- 기간 설명은 확정일/조회일을 각각 그 봉까지의 값으로 계산한다. 3봉 상태 확인과 ATR 파동 확정은 별개다. 미완료 봉은 잠정이다.
- 대파동과 거래량/가격 흔적이 같은 날짜에 있으면 한 툴팁으로 합친다. OFF·중/소 전환 때 흔적 원 툴팁을 복원하며 재렌더/토글 시 구독·예약 프레임을 정리한다.
- 수동 직선 등 작도·저장 형식/키·MA·거래량·가격 흔적·기간·줌은 변경하지 않는다. 범례 아래로 파동 머리글을 배치한다.
