# 9Pay UI 가이드

## 기본 방향

- PC 화면을 우선하고 모바일 반응형을 유지한다.
- 본문 영역은 넓게 사용한다.
- 모바일 Sub Menu는 가로 스크롤로 처리한다.
- 작은 카드는 필요하면 2열로 묶어 정보 밀도를 높인다.
- 장식보다 데이터의 의미와 가독성을 우선한다.

## 색상

| 의미 | 색상 |
|---|---|
| 상승·매수 | 빨강 `#d24f45` |
| 하락·매도 | 파랑 `#1261c4` |
| 다크 배경 | `#1A1A1A` |
| 다크 기본 글자 | `#F5EFE0` |

- 구조색은 배경과 글자 중심의 2색 체계를 유지한다.
- 상승·하락, 경고, 등급, 뱃지처럼 의미가 있는 색은 보존한다.
- 다크모드는 `html.dark` 클래스 방식이다.

## 변경 원칙

- 기존 CSS 선택자와 DOM 계약을 먼저 확인한다.
- PC와 모바일을 모두 검증한다.
- 한 위젯 수정으로 다른 위젯의 공통 스타일을 임의 변경하지 않는다.
- 차트, 호가, 수급 데이터의 색상 의미를 뒤집지 않는다.

## 공통 메뉴 정보구조

- 1차 텍스트 메뉴는 `홈 / 시장 / 종목 / 패턴·발굴 / 캘린더 / 커뮤니티 / MY` 7개다.
- 시장 하위에는 마켓 브리핑, 증시온도, 글로벌 시장지표, 코스피 선물을 둔다.
- 종목 하위에는 종목분석과 실시간 시세(`/page/stock-search`)를 둔다.
- 패턴·발굴 하위에는 현재 존재하는 차트패턴 스캐너만 둔다.
- 종목뉴스 URL과 기능은 보존하지만 공통 메뉴에는 노출하지 않는다.
- MY는 `/page/watchlist`로 이동하는 1차 텍스트 메뉴로 제공한다.
- 시장·종목·패턴·발굴은 드롭다운이나 화살표를 사용하지 않는다. 클릭하면 헤더 아래 고정형
  2차 메뉴 바를 열고, 하위 페이지에서는 현재 1차·2차 메뉴를 함께 활성화한다.
- 모바일은 1차·2차 메뉴를 각각 한 줄 가로 스크롤한다.

## 홈 정보 밀도

- 투자자별 매매동향은 기존 298px 수준 높이와 전체 행을 유지하고 PC에서 약 2/3 폭으로 배치한다.
- 오른쪽에는 증시온도·시장방향·수급·환율·주도/주의 업종과 규칙형 해석을 담은 오늘의 시장판을 둔다.
- 다음 행은 실시간 랭킹·오늘의 패턴·MY·주요 일정·실시간 공시 5개를 PC 한 줄에 같은
  폭·높이로 배치한다. MY는 `wl_codes_v1` 관심종목과 기존 묶음 시세를, 공시는 기존
  KIND/KRX 공시 RSS를 재사용한다.
- 상단 티커는 시장지표 전용이다. 뉴스·공시 스크롤 영역을 섞지 않는다.
- 기본 시장지표는 코스피·코스닥·원/달러·나스닥 선물·S&P500 선물·VIX·BTC·WTI다.
- 홈 마켓브리핑은 최신 4건을 대표 1개 + 중간 3개로 배치하며 양쪽 바깥 높이를 맞춘다.
- 시장 티커를 제외한 8개 홈 위젯은 핸들 드래그(모바일 450ms 길게 누르기), 맨 위/아래
  이동, 숨김/복원, 초기화를 제공한다. 순서와 숨김 상태는 `home_dashboard_layout_v1`에
  자동 저장하며 홈은 위젯 레지스트리만 관리한다.
- 숨긴 기능의 URL, 데이터 API, 분석 알고리즘은 변경하지 않는다.
