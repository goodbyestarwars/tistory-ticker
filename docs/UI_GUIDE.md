# 9Pay UI 가이드

## 기본 방향

- PC 화면을 우선하고 모바일 반응형을 유지한다.
- 본문 영역은 넓게 사용한다.
- 모바일 Sub Menu는 가로 스크롤로 처리한다.
- 작은 카드는 필요하면 2열로 묶어 정보 밀도를 높인다.
- 장식보다 데이터의 의미와 가독성을 우선한다.

## 색상

| 의미 | 색상 |
|---|---|
| 상승·매수 | 빨강 `#d24f45` |
| 하락·매도 | 파랑 `#1261c4` |
| 다크 배경 | `#1A1A1A` |
| 다크 기본 글자 | `#F5EFE0` |

- 구조색은 배경과 글자 중심의 2색 체계를 유지한다.
- 상승·하락, 경고, 등급, 뱃지처럼 의미가 있는 색은 보존한다.
- 다크모드는 `html.dark` 클래스 방식이다.

## 변경 원칙

- 기존 CSS 선택자와 DOM 계약을 먼저 확인한다.
- PC와 모바일을 모두 검증한다.
- 한 위젯 수정으로 다른 위젯의 공통 스타일을 임의 변경하지 않는다.
- 차트, 호가, 수급 데이터의 색상 의미를 뒤집지 않는다.

## 공통 메뉴 정보구조

- 1차 텍스트 메뉴는 `홈 / 시장 / 종목 / 패턴·발굴 / 캘린더 / 커뮤니티` 6개다.
- 시장 하위에는 마켓 브리핑, 증시온도, 글로벌 시장지표, 코스피 선물을 둔다.
- 종목 하위에는 종목분석과 실시간 시세(`/page/stock-search`)를 둔다.
- 패턴·발굴 하위에는 현재 존재하는 차트패턴 스캐너만 둔다.
- 종목뉴스 URL과 기능은 보존하지만 공통 메뉴에는 노출하지 않는다.
- MY는 텍스트 메뉴가 아니라 navbar의 아이콘으로 제공한다.
- PC 드롭다운은 hover, click, Tab, ESC를 지원하고 모바일은 1차·2차 메뉴를 각각 가로 스크롤한다.

## 홈 정보 밀도

- 실시간 랭킹은 거래량·상승률·하락률 탭 하나로 통합하고 탭별 5종목을 표시한다.
- 투자자별 매매동향은 일·주·월 및 코스피·코스닥 기능을 유지하면서 세로 여백을 줄인다.
- 주요 공시는 영향 가능성이 큰 명시적 제목 키워드를 우선하고 최대 5건만 표시한다.
- 홈 글 목록은 최신 3건만 남기고 마켓브리핑 전체보기 링크를 제공한다.
- 숨긴 기능의 URL, 데이터 API, 분석 알고리즘은 변경하지 않는다.
