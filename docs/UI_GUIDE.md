# 9Pay UI 가이드

## 기본 방향

### 전역 박스·페이지 배경 (2026-10-27)

라이트 모드 콘텐츠 박스는 공통 `css/liquid-glass.css`의 불투명 흰색(`#FFFFFF`) 면을 사용한다. 반투명 면과 유색 광택으로 흰색이 달라지지 않도록 한다. 메인·휴장·이야기·이용문서가 같은 면 토큰을 재사용하며 페이지 배경은 `#FEFDFA`다. 다크 모드와 상승·하락 등 의미색은 유지한다. 아래 과거 청회색 박스 지침은 이 규칙으로 대체한다.

푸터(서비스 링크·회사 정보 포함)와 관심종목 사이드바의 바탕은 콘텐츠 카드 면이 아닌 페이지 면으로 분류하며 `--page-bg`(`#FEFDFA`)를 사용한다. 이야기 시리즈는 바깥 푸터 영역을 페이지 면으로 유지하고, 독립된 이야기 박스·카드에만 흰색 공통 면을 적용한다. 이야기 박스는 홈 공통 최대 너비 `--home-content-max`와 좌우 16px 여백에 맞춰 중앙 정렬한다. 이 범위 구분은 PC·모바일에 공통 적용한다.


### 단락·구분선·박스 사이 여백 (사용자 상시 지침, 2026-10-25)

단락은 서로 붙이지 않는다. 가로줄과 네모박스로 구역을 나눌 때도 구역 사이 및 선과 내용 사이에 항상 여백을 둔다.
`css/ui-spacing.css`를 메인 `style.css`와 독립 문서 `css/legal.css`가 함께 불러오는 것이 유일한 여백 기준이다. 화면별 고정값이나 모바일 예외로 이 값을 다시 정의하지 않는다.
본문 단락 간격은 `--ui-paragraph-gap`(PC14px/760px 이하12px), 구역·독립 박스 간격은
`--ui-section-gap`(PC20px/모바일16px), 구분선 아래 안쪽 간격은 `--ui-card-padding`(18px/14px)을 쓴다.
기존에 더 크게 지정한 구역 간격(예: 대표 지수 흐름의32px)은 유지한다.
홈·휴장·증시온도·시장지표·검색기·종목분석·캘린더·MY·계산기·이용문서의 독립 카드/그리드는 같은 간격과 안쪽 여백을 쓴다. 이야기 캐러셀은 간격뿐 아니라 카드 폭 계산에도 같은 토큰을 사용한다. 헤더 작업 버튼의 예약 공간과 더 큰 편집형 여백은 보존한다.
표의 행·시세 숫자 칸·차트 내부에는 이 단락 규칙을 일괄 적용하지 않는다.

### 홈 시장 정보 블록·부제목 (2026-10-27)

`ui-content-block`은 지수 카드와 같은 공통 면·글래스·테두리·14px 모서리·공통 안쪽 여백을 재사용한다. 국내/미국 시장 제목과 방향·온도를 한 개요 블록으로 묶고, 시장 내부 흐름·시장 핵심 지표/미국 시장 요약·주요 ETF 수익률·경제뉴스 위 관심종목 주간 공시/주요일정·경제 종합뉴스는 각각 독립 블록이다. 시장판과 경제뉴스의 바깥 열은 테두리·배경·그림자·안쪽 여백이 없는 배치 컨테이너로 두며 개별 블록을 큰 상자로 다시 둘러싸지 않는다. 원래 지수 카드·시세·차트·공시 가로 이동은 유지한다. 시장판 자식 블록 간격은 부모 gap 하나로 `--ui-section-gap`을 적용한다.

이 블록 제목은 공유 `ui-section-title`의 MaruBuriBold·700·`--ui-section-size`(17px)를 쓴다. 휴장 화면의 원유·금, 이번/다음 주 주요 일정, 미국 국채금리·환율, 24시간 가상자산, 바이낸스 주식·ETF 선물에도 같은 부제목만 적용하고 기존 배치는 유지한다. 수치·차트·본문·보조 문구는 기존 UI 글꼴이다.

### 홈 시장 전환 세그먼트·너비·여백 (2026-10-27)

`한국증시 / 미국증시 / 휴장`은 홈 전용 3분할 세그먼트 버튼이다. `js/skin-main.js`의 기존 `data-home-market-switch` 값과 클릭·선택·휴장/카운트다운 연결은 그대로 두고, 아이콘은 `aria-hidden`으로 분리한다. 휴장 아이콘은 한국·미국 국기 이모지와 같은 계열로 맞추려고 📅 이모지를 쓴다(2026-10-31, 모바일에서 휴장만 선 아이콘이라 달라 보인다는 지적. 10/27의 calendar SVG를 되돌림).
`style.css`의 `body#tt-body-index .home-editorial-page .home-market-switch`가 트랙·버튼·선택·호버·키보드 포커스·다크·모바일 스크롤을 단독 정의한다. 예전 밑줄 `::after`는 사용하지 않는다. `css/home-market-board.css`에는 별도 탭 스타일을 복제하지 않는다.

홈의 시장판·경제 종합뉴스·실시간 종목판·마켓브리핑·이야기 시리즈는 공통 `--home-content-max:1440px`을 기준으로 한다. 홈에서만 `.main-layout` 최대폭을 1440px + 좌우 16px으로 설정하고, 예전 마켓브리핑의 뷰포트 밖 확장 규칙은 제거했다. 관심종목 드로어를 열어도 모든 섹션은 남은 콘텐츠 폭을 따른다. 이야기 시리즈 원본 `.site-footer-learn`은 브리핑과 같은 공통 테두리·면·모서리·여백을 적용하며, 휴장 시 원본 노드가 `#homeWeeklyReport`로 이동해도 같은 카드로 표시한다.

모바일 탭-시장 간격은 `.home-editorial-page`의 `--ui-section-gap` 하나만 사용한다. `.home-market-toolbar`의 중복 아래쪽 margin과 시장 제목의 과거 30px 패딩은 제거한다. 작은 화면은 탭 그룹 자체 가로 스크롤을 허용하고 시장 카드·뉴스/브리핑·이야기 카드는 가로 넘침 없이 채운다. PC·모바일·다크모드에서 카드 폭·여백·선택 상태를 함께 확인한다.

### 이야기 시리즈 25개 문서 · 교재형 레이아웃과 초기 렌더 (2026-10-26)

- `learn/*.html`은 `<body class="learn-page">`로 명시적으로 범위를 구분한다. 공유 CSS `css/legal.css`의 이야기 전용 스타일은 `body.learn-page .legal-wrap` 아래에서만 적용하며 법적 고지 및 `legal/guide.html`을 건드리지 않는다.

- 밝은 그림 바탕 `fig-soft`/`fig-soft2`/`fig-white`는 블루그레이를 사용하고 도표 텍스트 `fig-ink`는 진한 색, `fig-on-strong`은 진한 상승/하락 막대 안의 밝은 텍스트, `fig-on-accent`는 금색 계열 막대 위의 진한 텍스트다. 코인 반감기 '50개' 라벨은 `fig-ink`를 쓴다. 상승/하락의 의미색은 변경하지 않는다.

## 공통 UI 모듈 표준

### 차트 공통 엔진과 지지·저항 밴드 (2026-10-12)

실시간 시세 차트 전체화면 상단은 높고 적당한 폭의 종목명·코드 검색창으로 종목을 바꾸며 이전·다음 버튼은 표시하지 않는다. 원래 화면의 `독립 차트`로 모달을 열고, 모달 안의 `화면 가득`은 브라우저 영역 전체로 확장한다. `창 크기`는 모달 크기로 돌아오고 상단 `줄이기`는 전체화면을 닫고 원래 화면의 차트로 돌아간다.

종목 차트는 HTS처럼 마우스 휠을 위로 굴리면 봉이 커지고 아래로 굴리면 봉이 작아진다. 전체화면 상단의 `−`·`+`도 같은 봉 크기 조절을 제공한다. 가격·봉 데이터 자체는 바꾸지 않는다. 전체화면에서는 거래량·RSI 영역을 기본보다 작게 배치하고 패널 구분선을 드래그해 높이를 조절할 수 있다. 실시간 검색 차트의 큰 `독립 차트` 버튼으로 전체화면을 열며, 전체화면 검색창은 폭을 제한하고 높이를 48px로 표시한다.

지지·저항은 `chart-sr.js`의 기존 스윙·군집 계산값을 그대로 사용한다. 각 지지·저항 최대 3개를 실제 `low~high` 범위의 연한 빨강·파랑 반투명 가로 밴드로, 중심 가격을 가는 점선으로 표시한다. 우측 라벨은 `지지 1 44,800~47,200` 형식이며 숫자는 계산 결과를 가격 형식에 맞춰 만든다. 라벨은 가격축 안쪽에 두고 겹치면 세로 위치만 조정한다. 차트 전체화면·종목 변경·확대 시 공통 모듈을 다시 그리며 차트 교체 때 구독과 관찰자를 정리한다.

### 실시간 시세·차트 검색의 주요 지수

`/page/stock-search`와 공통 사이드바 검색에서 코스피·코스닥·나스닥·S&P&500·다우존스·필라델피아 반도체지수(SOX)를 지수명/영문 별칭으로 찾는다. 지수는 `INDEX:<symbol>` URL로 열고 기존 공개 `/futures?symbols=...&days=500`의 최근 값과 `MarketChartHistory`의 과거 OHLC를 날짜로 병합해 최근 3년을 표시한다. 이력 파일을 못 받으면 기존 최근 차트로 표시한다. 현재값은 화면 표시 중 30초마다 조회하며 공급자 `updated_at`을 함께 표시한다. 마우스를 올린 봉의 시가·고가·저가·종가를 보여 준다(주봉·월봉은 해당 기간 집계값). 지수 차트의 전체화면 버튼은 공용 모달에 지수 패널을 옮겨 봉 전환·그리기 도구를 함께 유지한다. `/futures`의 현물 지수에는 분봉이 없으므로 분봉을 가장해 그리지 않는다. 일반 종목 호가·관심종목·뉴스 경로로 지수를 보내지 않는다.


상단 큰 검색창의 바로가기 칩은 코스피·코스닥·나스닥·S&P&500·다우존스 다섯 지수로 연결한다. 지수 상세는 기존 `NineChartData.barsForTimeframe`으로 일봉을 주봉·월봉으로 집계하고, 공용 `NineChartDrawing`의 직선·동그라미·박스·가로선·연필을 브라우저에 종목·봉 주기별로 저장한다. 지수 그리기는 계정 동기화하지 않는다. 이 다섯 현물 지수의 실제 분봉 소스는 현재 `/futures`에 없어서 분봉 버튼을 비활성화하고 일봉을 분봉처럼 만들지 않는다.

최근 신호는 실제 시각 최신순5종목이며 날짜만 있으면 시각 미제공을 표시한다. 26px 원형 로고는 기존 `img/stock-icons/{종목코드}.svg`와 `StockIconFallback`을 재사용한다. 최종 이미지 실패 시 같은 크기의 기본 이니셜을 유지한다. 로고 및 장식 변경은 이 목록에만 한정한다. 스캔 추이는 공통 `IndicatorBoard.createChart`의 SVG·축·툴팁·테마를 재사용하며 기간 전환 때 별도 API 호출을 만들지 않는다. 현재 검색 결과는 일별 저장 이력에 합치지 않고 최근 신호 배지에서 출처를 구분한다. 현재 결과가 있어도 일별 이력이 비어 있으면 두 상태를 함께 안내한다. 원형 상태는 서버 lastExecution.state를 따른다. running은 진행 정보가 오래돼도 진행 중과 마지막 실제 진행률을 유지한다. 25종목 단위 보고 사이의3분 초과 갱신 지연은 보조 안내만 표시하며 완료/실패/중단으로 추정하지 않는다. waiting도 서버 상태가 바뀔 때까지 대기를 유지한다. CSS 준비 전 원형 상태를 만들지 않으며 검색 로딩은 공통 NineUI.state의 파형 없는 텍스트 변형을 쓴다.
