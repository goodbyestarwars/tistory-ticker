# 9Pay UI 가이드

## 기본 방향

- PC 화면을 우선하고 모바일 반응형을 유지한다.
- 본문 영역은 넓게 사용한다.
- 모바일 Sub Menu는 가로 스크롤로 처리한다.
- 작은 카드는 필요하면 2열로 묶어 정보 밀도를 높인다.
- 장식보다 데이터의 의미와 가독성을 우선한다.

## 색상

| 의미 | 색상 |
|---|---|
| 상승·매수 | 빨강 `#d24f45` |
| 하락·매도 | 파랑 `#1261c4` |
| 다크 배경 | `#1A1A1A` |
| 다크 기본 글자 | `#F5EFE0` |

- 구조색은 배경과 글자 중심의 2색 체계를 유지한다.
- 상승·하락, 경고, 등급, 뱃지처럼 의미가 있는 색은 보존한다.
- 다크모드는 `html.dark` 클래스 방식이다.

## 변경 원칙

- 기존 CSS 선택자와 DOM 계약을 먼저 확인한다.
- PC와 모바일을 모두 검증한다.
- 한 위젯 수정으로 다른 위젯의 공통 스타일을 임의 변경하지 않는다.
- 차트, 호가, 수급 데이터의 색상 의미를 뒤집지 않는다.

## 공통 UI 모듈 표준

새 UI는 `css/ui-system.css`의 토큰과 컴포넌트 클래스를 우선 사용한다. 버튼은 역할별로
`ui-btn-a`(주요 실행), `ui-btn-b`(보조 실행), `ui-btn-c`(이동·더보기), `ui-btn-d`(텍스트형)을
사용하고, 의미가 드러나는 별칭인 `ui-btn-primary`, `ui-btn-secondary`, `ui-btn-soft`,
`ui-btn-text`도 지원한다. 기본 모듈은 `ui-module`로 외곽선 없이 아래 구분선만 사용하며,
표·입력처럼 감싸기가 필요한 경우에만 `ui-module-boxed`를 사용한다. 섹션 제목은
`ui-section-heading`, 반복 행은 `ui-list-row`를 사용한다. 상승·하락 색은 버튼에 재사용하지
않고 시세·상태 데이터에만 적용한다. 탭은 `ui-btn ui-btn-tab`을 사용하며, 활성 상태는
검정 계열 채움형, 비활성 상태는 얇은 테두리형으로 통일한다.

## 공통 메뉴 정보구조

국내 실시간 종목판의 `체결강도` 탭은 KIS KRX 당일 체결강도 내림차순이다. PC는 현재가 다음에 강도 열을 추가하고 모바일은 종목/현재가/강도3열로 표시한다. 100 초과 빨강·미만 파랑, 누락은 미수신. 순위/강도 약30초 스냅샷과 현재가 WebSocket 갱신을 구분하며 기존 ETF·ETN 토글을 유지한다. API·캐시·검증은 `DOMESTIC_VOLUME_POWER.md`.

- PC 하위 메뉴는 JS가 관리하는 `.is-open` 한 상태로만 표시한다. 포인터·클릭·키보드 포커스가 바뀌어도 한 그룹만 열고, 외부 클릭과 ESC는 모두 닫으며 `aria-expanded`를 같은 상태로 맞춘다.

- 1차 텍스트 메뉴는 `홈 / 시장 / 종목 / 종목검색 / 캘린더 / 커뮤니티` 6개다.
- 시장 하위에는 마켓 브리핑, 증시온도, 글로벌 시장지표, 코스피 선물을 둔다.
- 종목 하위에는 종목분석과 실시간 시세(`/page/stock-search`)를 둔다.
- 종목검색 하위에는 차트검색과 전략검색을 둔다.
- 종목뉴스 URL과 기능은 보존하지만 공통 메뉴에는 노출하지 않는다.
- 관심종목은 별도 MY 메뉴에 두지 않고 모든 페이지 오른쪽 끝의 고정 탭으로 열고 닫는 드로어로 제공한다.
- 관심종목 블록은 마우스 드래그앤드롭으로 같은 그룹 내 순서와 다른 그룹 이동을 저장한다.
- 시장·종목·종목검색은 드롭다운이나 화살표를 사용하지 않는다. 클릭하면 헤더 아래 고정형
  2차 메뉴 바를 열고, 하위 페이지에서는 현재 1차·2차 메뉴를 함께 활성화한다.
- 모바일은 1차·2차 메뉴를 각각 한 줄 가로 스크롤한다.

### 홈 시장판 정보·지수·실시간 등락률 (2026-10-12)

국내 홈 시장판은 시장 방향(급락·강한 약세 등)과 증시온도를 상단에 두고, KOSPI·KOSDAQ 등락률은 지수 카드에 한 번만 표시한다. 상승·보합·하락 종목 수와 비율 막대는 하단 ‘시장 내부 흐름’에만 표시한다. 지수 숫자는 PC 27px·모바일 24px, 등락률은 13.5px 프리텐다드 기준이다.

홈 KOSPI·KOSDAQ 지수 차트도 나스닥과 동일한 30분 기본 막대·화살표 면적 전환·관측 고저·옅은 색상으로 표시한다. 정규장09:00~15:30 최대14개, KST. 기존 국내 시세의 공급자시각/OPEN 관측만 저장하고 미수집 과거는 만들지 않는다. 투자자 지표도 같은 막대·면적 표현/색상을 쓰되 누적 순매수의 0선을 기준으로 한다. 공용5년 일봉 이력은 다른 상세 차트를 위해 보존한다. 미국 홈의 나스닥 종합·S&P500 현물, 본장 외 나스닥100·S&P500 CME 선물, KOSPI200 야간선물은 `/home-session-chart`의 최근 한 세션을 30분별로 표시한다. 기본 막대, 화살표로 세 차트를 함께 면적 전환, 관측 고저·시작일·시각·개수를 표시한다. 미국은 뉴욕시간(DST 자동), 현물 09:30~16:00(최대 14시점), CME 18:00~다음 17:00(최대 47시점), 국내 야간은 기존 18:00~다음 06:00 범위를 쓴다(종료 경계 수집 여부에 따라 실제 개수는 더 적다). 막대·면적은 같은 거래일 시세의 가격-전일대비로 확인한 전일 종가 기준으로 위 빨강·아래 파랑이며 캔들이 아니다. 전일 종가는 세션별로 저장하고, 미확인 시 중립색과 미확인 문구를 사용한다. 다른 세션의 기준을 빌리지 않는다. 미국 관측은 배포 이후 기존 30초 시세 결과만 저장하고 공급자 지연 가능을 표시, 야간은 기존 실제 분봉 집계다. 화면은 1분마다 재조회하며 실제 공급자·분봉 수집 주기보다 빠른 갱신을 보장하지 않는다. 누락 구간 보간·과거 일봉 복원 없음. 마지막 세션은 장후 보존하고 새 세션의 실제 자료가 도착하면 교체한다. 개별 종목·시장지표 상세 차트는 유지한다.

다섯 홈 미니차트의 선 오른쪽 끝에는 24px 안의 은색 지진계 펜을 둔다. 첫 표시 때 실제 시세 좌표를 따라 1.8초 동안 선을 드러내고, 새 시세가 끝에 추가되거나 마지막 값만 바뀌면 마지막 구간만 0.42초 동안 그린다. 같은 데이터의 재조회, 탭 재진입, 페이지 숨김 뒤 복귀에는 전체 애니메이션을 다시 시작하지 않는다. `prefers-reduced-motion`이면 즉시 완성 상태로 표시한다.

실시간 종목판의 변화 음영은 직전 틱 방향이 아니라 **현재 전일 대비 등락률의 부호**를 따른다(양수 빨강·음수 파랑·0 무음영). 1.6초 고정 배경으로 표시하며 새 틱이 오면 기존 해제 타이머를 취소한다. 크기·열 정렬을 바꾸는 알약·강제 리플로우·재시작 애니메이션은 사용하지 않는다.

홈 투자자 동향은 KOSPI·KOSDAQ 외국인 **누적 순매수**의 정규장 관측 기록을 표시한다. 09:00~15:30을 30분 구간 최대 14개로 배치하고 기본은 막대, 좌우 화살표로 두 시장을 함께 면적 차트로 전환한다. 0선 기준 매수 빨강·매도 파랑이며 고점·저점은 구간의 마지막 값뿐 아니라 기존 1분 폴러가 관측한 중간 극값도 유지한다. 같은 구간은 새 관측으로 덮어쓰고 다음 구간은 새 막대를 추가한다. 미수집 구간은 채우거나 면적으로 이어 붙이지 않는다. 화면은 기존 1분 주기로 재조회하고 전환 상태를 유지하며 실패 시 기존 차트를 보존한다. 날짜·관측 시각·확보 개수를 표시하고 장중 기록이 없으면 일별 최근값과 ‘장중 기록 수집 전’을 구분한다. 장후·주말에는 마지막 기록을 보존하고 새 거래일 개장 시 전일 막대를 지운다. 과거 일별 자료로 장중 기록을 복원하지 않는다.

### 미국 경제 발표와 주식의 관계 (2026-10-08)

`갱신` 버튼은 VM의 `PUT /futures/refresh-macro`로 FRED 원본 확인을 요청하고 완료까지 상태를 조회한 뒤 `/futures`를 다시 읽는다. 화면에는 한국시간 확인 시각과 일부 실패 여부를 표시한다. 서버에서 5분 이내 재요청은 같은 결과를 반환한다. 새 발표가 없는 경우 수치는 유지된다.

생산자물가지수 행은 BLS 표제 발표와 같은 FRED `PPIFIS`(최종수요·계절조정, `US_PPI_FINAL_DEMAND`)를 쓴다. 전월 대비율은 소수 첫째 자리로 표시한다. 기존 `PPIACO` 전 품목 지수(`US_PPI`)는 다른 계열이므로 화면의 5년 차트에 섞지 않는다.

시장·캘린더의 10개 경제 결과 카드에서 높으면/낮으면/좋은 흐름을 금리·기업 실적·관련 업종에 연결한다. 물가·고용의 예상 대비 변화와 실제 미국채 금리 반응을 구분하며, 경기침체로 인한 금리 하락을 주식 호재로 단정하지 않는다. 설명은 일반적인 전달 경로이며 예상치 데이터를 수집하거나 실시간 매매 신호를 계산하지 않는다. 정적 문구 변경으로 VM 요청·저장량은 늘지 않는다.

`/page/stock-search`와 공통 사이드바 검색에서 코스피·코스닥·나스닥·S&P&500·다우존스·필라델피아 반도체지수(SOX)를 지수명/영문 별칭으로 찾는다. 지수는 `INDEX:<symbol>` URL로 열고 기존 공개 `/futures?symbols=...&days=500`의 최근 값과 `MarketChartHistory`의 과거 OHLC를 날짜로 병합해 최근 3년을 표시한다. 이력 파일을 못 받으면 기존 최근 차트로 표시한다. 현재값은 화면 표시 중 30초마다 조회하며 공급자 `updated_at`을 함께 표시한다. 마우스를 올린 봉의 시가·고가·저가·종가를 보여 준다(주봉·월봉은 해당 기간 집계값). 지수 차트의 전체화면 버튼은 공용 모달에 지수 패널을 옮겨 봉 전환·그리기 도구를 함께 유지한다. `/futures`의 현물 지수에는 분봉이 없으므로 분봉을 가장해 그리지 않는다. 일반 종목 호가·관심종목·뉴스 경로로 지수를 보내지 않는다.


상단 큰 검색창의 바로가기 칩은 코스피·코스닥·나스닥·S&P&500·다우존스 다섯 지수로 연결한다. 지수 상세는 기존 `NineChartData.barsForTimeframe`으로 일봉을 주봉·월봉으로 집계하고, 공용 `NineChartDrawing`의 직선·동그라미·박스·가로선·연필을 브라우저에 종목·봉 주기별로 저장한다. 지수 그리기는 계정 동기화하지 않는다. 이 다섯 현물 지수의 실제 분봉 소스는 현재 `/futures`에 없어서 분봉 버튼을 비활성화하고 일봉을 분봉처럼 만들지 않는다.


### 대파동 보조 설명·거래량/가격 흔적 (2026-10-20 통합)

별도 `추세 상태` 체크박스와 상단 4개 상태 박스를 제거했다. 기간별 종가 변화(1/3/6/12개월, ±3/6/9/12%, 3봉 확인)는 `파동 분석 > 대파동`의 보조 설명으로만 쓴다. 방향 일치·장기 흐름 역행·전환 확인 중을 툴팁에 표시하며 ATR 극점·박스·확정일·중/소파동은 바꾸지 않는다. 선택한 파동의 확정 영역은 실선, 진행 중 영역은 점선이다. 중/소파동의 상위 윤곽은 종전의 옅은 점선을 유지한다.

대파동 머리글은 `현재 자료로 재구성`을 명시한다. 십자선 날짜까지의 자료로 재분석한 `당시 자료 기준`과 현재 그림의 `사후 재구성` 영역·실제 확정일·확정 당시 보조 설명을 구분한다. 과거 극점 날짜에 미래 확정을 소급 표시하지 않는다. 대파동을 켠 동안 같은 날짜의 거래량/가격 흔적을 한 툴팁에 합쳐 겹침을 피하며, 중/소파동 전환 또는 파동 OFF 때 원 흔적 툴팁으로 복원한다. 저장된 설정·수동 작도·MA·거래량·줌은 보존한다.

흔적은 상세 관찰이 기본이고 날짜당1기호·축소16px 밀도 조절을 유지한다. 중요 모드 비교 API는 검증 통과 유형0개이며, 2026-10-21부터 선택창 없이 상세 관찰만 표시한다. 실제 수급 주체나 매집으로 해석하지 않는다. 과거 흔적 검증은 [CHART_REGIME_TRACES_2026-10-20.md](CHART_REGIME_TRACES_2026-10-20.md), 통합 검증은 [MAJOR_WAVE_CONTEXT_2026-10-20.md](MAJOR_WAVE_CONTEXT_2026-10-20.md)를 따른다.

### 종목 요약 통합·일봉 요약 (2026-10-21)

차트검색의 선택 종목 요약 한 곳에 시가/고가/저가/현재가와 실제 OHLC 비율의 작은 일봉을 둔다. 봉의 빨강/파랑은 현재가 대 시가 기준이며 전일 대비 등락색과 다를 수 있다. 누락/모순 OHLC에는 봉을 만들지 않고 자료 부족을 표시한다. 기준 일봉 날짜를 표시하고 거래량은 기존 결과표·차트에서 유지하며 요약에 중복하지 않는다.

내장 호가 위젯은 `onSummary`/`onBookStatus`로 같은 자료와 호가 상태를 상위 요약에 전달하고 중복 머리글·요약·호가 없음 박스를 생략한다. 단독 호가 페이지는 기존 머리글·요약을 유지한다. 유효 호가가 있으면 매도10호가→현재가/등락→매수10호가 순서, 빈 호가에서도 호가창을 숨기지 않는다. 10+10 위치와 중앙 현재가를 유지하며 미수신 칸은 —로 표시한다. 직전 실수신 호가가 있으면 마지막 수신 자료라는 안내와 함께 보존한다. 기존 소켓·폴링·계산·주문은 바꾸지 않는다.

차트검색/종목분석의 흔적 `표시 범위` 선택창을 제거하고 기존 상세 관찰을 유지한다. 중요 모드 비교 API는 보존하지만 UI에서 선택하지 않는다. 범례는 `● 거래량  ■ 112·224·448선  ▲ 고가 재돌파`다. 장기선은112/224/448일 단순이동평균 관찰이며, 고가 재돌파는 대량 윗꼬리봉 이후 저점 방어와 그 봉의 고가를 종가로 넘어선 경우다. 장기선 회복과 다르며 판정은 변경하지 않는다.

후속 복구: 호가 없음/로딩/오류가 내장 호가창 자체를 숨기던 처리를 제거했다. 상단 요약은 PC 약70px·모바일 약105px로 압축하며, 종목명·현재가·등락·작은 봉·시가/고가/저가를 한 도구줄에 배치한다. 기준일은 봉의 설명에 보존한다. 호가 HUD는3열로 압축하고 호가20행은22px 간격으로 표시한다. 현재가 표시는 상단/호가 중앙에서 같은 요약 값을 사용한다.
