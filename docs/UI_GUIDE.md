# 9Pay UI 가이드

## 기본 방향

- PC 화면을 우선하고 모바일 반응형을 유지한다.
- 본문 영역은 넓게 사용한다.
- 모바일 Sub Menu는 가로 스크롤로 처리한다.
- 작은 카드는 필요하면 2열로 묶어 정보 밀도를 높인다.
- 장식보다 데이터의 의미와 가독성을 우선한다.

## 색상

| 의미 | 색상 |
|---|---|
| 상승·매수 | 빨강 `#d24f45` |
| 하락·매도 | 파랑 `#1261c4` |
| 다크 배경 | `#1A1A1A` |
| 다크 기본 글자 | `#F5EFE0` |

- 구조색은 배경과 글자 중심의 2색 체계를 유지한다.
- 상승·하락, 경고, 등급, 뱃지처럼 의미가 있는 색은 보존한다.
- 다크모드는 `html.dark` 클래스 방식이다.

## 변경 원칙

- 기존 CSS 선택자와 DOM 계약을 먼저 확인한다.
- PC와 모바일을 모두 검증한다.
- 한 위젯 수정으로 다른 위젯의 공통 스타일을 임의 변경하지 않는다.
- 차트, 호가, 수급 데이터의 색상 의미를 뒤집지 않는다.
