## 2. 이 세션에서 알아두면 좋은 것

### 2-1. 측정 도구를 먼저 의심할 것

`page-speed`의 "쓸 수 있게 되기까지" 기준 3개가 **껍데기를 세고 있었다.** 홈은 "불러오는

걸리면 실제보다 빠르게 나온다. 셀렉터가 낡으면 장애처럼 보인다. 이 교정 전후의 속도
값은 **서로 비교하지 말 것.**

### 3-3. 휴장 대시보드 목록 깨짐 (`78180e8`)

목록 리셋과 행 레이아웃이 **조상 선택자에만** 걸려 있었다.

```css
.hwr-columns ul, .hwr-schedule ul { list-style: none; margin: 0; padding: 0; }
.hwr-columns li { display: flex; justify-content: space-between; border-top: ... }
```

다른 섹션은 전부 `<div class="hwr-columns">`로 목록을 감싸는데 `pastOutcomeList()`만
`<ul>`을 `<section>` 바로 밑에 둔다. 그래서 "지난 2주 스윙 추천 결과" 목록만 기본 불릿 +
`padding-left: 40px`로 떨어졌다(로컬 실측: `list-style disc` / `40px` / `margin-top 16px`,
대조군은 `none` / `0px` / `0px`).

**"이 목록도 `.hwr-columns`로 감싸라"가 아니라 리셋을 컴포넌트 자신에 걸었다.** 배치가
달라져도 다시 안 깨진다. 다크모드 구분선 색도 같은 범위로 넓혔다.

### 3-4. `/foreign-flow` 직렬 구간 제거 (`78180e8`)
