## 범위와 신뢰 수준

- 검색기·차트검색·전략검색·스캔 운영/추적에 관련된 과거 작업기록 101건과 초기 커밋 13건을 날짜순으로 연결했다. 판정뿐 아니라 목록·표시·속도·오류·데이터/이력 보존 변경도 포함한다.
- 검색으로 확인된 기록의 색인이다. 저장소 밖 대화·삭제된 기록까지 완전 복원했다는 뜻은 아니다. 날짜는 KST이며 커밋은 작성 시각 기준이다. 같은 날짜의 행 순서는 실제 작업 순서가 아닐 수 있다.
- `과거 작업기록`의 검증·배포 내용은 원문 작성 당시의 기록이며 이번 작업에서 재실행하지 않았다. `커밋 확인`은 저장소 반영 근거로서 실제 서버 배포/정상 운영/수익성 확인과 구분한다.
- 서로 다른 당시 보고(예: 미배포 → 배포 완료)는 지우지 않았다. 후속 수정·원복·현재 기준은 [검색기 변경·검증 대장](SCANNER_CHANGELOG.md)을 먼저 본다.
- 원문 링크는 복원 당시 커밋 `dec30ed`에 고정했다. 작업이력 상단 추가·보존본 이동으로 근거 줄이 바뀌는 문제를 피한다. 원문을 이 파일에 복제하지 않는다.
- 이 색인 추가/보정 시 원문 링크를 남기고, 실행·배포·성과를 제목만으로 추정하지 않는다.
