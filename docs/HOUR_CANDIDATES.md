# 장중 선택 종목의 1시간 방향 판단

현재 사용자 목표는 먼저 **확인 당시 가격보다 1시간 뒤 오를지 내릴지** 판단하는 것이다. +3% 수익/−3% 손절 후보 찾기는 현재 화면의 목적에서 제외했다. `hour-direction-rules-v6`은 학습·검증되지 않은 방향 가설이며 `validated:false`, `probability:null`이다. 이전 목표 이동폭 규칙/검증 기록은 [v3~v5 명세 보관본](history/HOUR_DIRECTION_RULES_V3_V5.md)에 보존한다.

2026-10-09: 계산식은 유지하고 [전진 성과 검증](HOUR_DIRECTION_VALIDATION.md)을 추가했다. 별도 불변 SQLite 기록과 기존 VI 루프/체결 응답 재사용으로 60분 뒤 KIS KRX 체결을 평가한다. 기존 회전 로그도 유지한다. 아래 '미집계' 설명은 초기 v6 상태이며 현재 표본·성과는 `/hour-direction/performance`에서 확인한다. 성과 표본 수와 소프트웨어 회귀 테스트 수를 구별한다.

## 사용과 비교 기준

사용자가 종목을 클릭하거나 직접 검색·선택하면 `1시간 방향 : 상승가능 / 하락가능 / 판단 어려움`과 바로 아래 짧은 근거를 표시한다. ↻는 수동 재확인이다. URL 자동진입·차트 갱신·만료에는 방향 API를 호출하지 않는다. 만료는 로컬에서 표시만 한다. UI 도움말도 +3% 대신 1시간 뒤 방향·정확도 미검증을 설명한다.

기준가는 같은 KIS KRX의 확인 당시 최근 체결가 `referencePrice`이다. 매수 체결가나 주문 가격이 아니다. 판단을 평가할 때는 확인+60분 시점의 같은 출처·시장 가격과 비교해 상승/하락/동률을 나눈다. 중간 고가 터치나 당일 누적 등락률을 성공으로 세지 않는다. 현재는 그 미래 성과를 집계·검증하지 않았다.

국내 거래일09:05 이상14:30 미만에만 확인하며 정규장 마감까지 다음60분을 확보하지 못하면 보류한다. 장외에는 공급자를 조회하지 않는다.

## 간단한 방향 규칙

가격이 우선이다. 최근5개 완결 분봉 시작 가격 대비 최근 종가가 상승하고 최근 최대30분 VWAP 근사 이상이면 상승 가격 조건이다. 이에 저점 상승 패턴 **또는** 체결강도105이상이 확인되면 상승가능으로 표시한다. 하락은 반대 가격 조건과 고점 하락 패턴 **또는** 체결강도95이하를 요구한다. 체결강도만 높거나 낮다고 방향을 만들지 않는다. 현재 체결가의 역방향 이동 허용폭은 max(종가0.2%, KRX호가1칸)이다.

저점 상승·고점 하락이 함께 나타나거나 가격/확인 근거가 맞지 않으면 보류한다. 매도우위인데 가격이 횡보·반등, 매수우위인데 횡보·하락인 경우 그 이유를 짧게 표시한다. 최근 거래량 가속이1미만이면 `거래량은 약해`를 덧붙일 뿐 보류하지 않는다. 목표 이동폭 계산·±3% 도달 조건·전일 거래량 비교·벽 잔량 부담 조건은 이 판단에서 제거했다.

같은 출처(KIS KRX)의 연속 완결 분봉·실제 체결강도·최신 호가/체결이 필요하다. 현재/미래 봉을 쓰거나 누락 봉을 메우지 않는다. 공급자 시각 각각10초 이내이고 최종 응답에도 신선도를 재확인한다. 수집 중 분 변경, 오래된/누락된 시세, 정지/정지여부 불명, 넓은 스프레드, 이미 급등(+5%)·한 번의 점프/급락(1.5%) 방어는 유지한다. 전일 거래량·+3% 상한가 조건은 방향 입력이 아니므로 해당 후보 API의 검증 누락/탈락을 방향으로 가져오지 않는다.

문턱의 예측 정확도나 체결강도 단독 대비 우위는 아직 검증되지 않았다. 미래 평가 시 거래일별 분리, 겹치는1시간/반복확인의 종속성, 같은 시장 가격을 지켜야 한다. 현재 테스트는 동작 계약 검증이며 예측 성공률이 아니다.

## API 및 VM 부담

공개 `GET /hour-direction?code=035420&name=NAVER`. 반환: code,name,direction,label,reason,checkedAt,expiresAt,horizonMinutes:60,objective:direction,referencePrice,referenceBasis,probability:null,validated:false,rulesVersion,sourceStatus,recorded. 호환 필드 targetPct,stopPct,entryPrice,targetPrice,stopPrice는 **항상null**이다. 근거 변수는 기존 로컬 회전 기록에만 둔다. 장외/자료 검증 전에는 referencePrice도null이다.

직접 확인1종목, 워커1개, 전역 수동 작업 동시1개, 두 수동 API 합쳐 IP분당3회, KIS 요청 시작0.1초 간격을 유지한다. 작업 예산30초/개별 읽기4초, 화면45초 중단이며 진행중 호출이 끝날 때까지 잠금을 유지한다. 예산은 토큰 발급·잠금·기존재시도를 포함한 HTTP응답 시간 보장이 아니다. 바쁜 요청409, 공급자 확보 실패503, no-store이다.

v6 방향 수집은 전일 확정 거래량 조회를 생략해 **분봉·현재시세·호가·체결의 정상4회**로 고정한다(토큰·기존재시도 별도). 분봉1회에서 최근30분만 사용하고 추가 페이지/과거조회/폴러/VM프로세스/타이머는 없다. 기존 `hour_candidate_checks.jsonl`5MB 및 `.1` 회전을 공유하며 IP·키·주문정보를 남기지 않는다. 기록 criteria도 objective:direction, targetPct/stopPct:null이다.

## 기존 후보 API 보존

`/hour-candidates`의 오전09:05~09:15·매수가+3%/−3%·순위 일부/최대24개·기존조건·전일거래량조회는 호환용으로 유지한다. 현재 검색·호가 화면에서 사용하지 않는다. 관련 이전 규칙은 보관본과 API_REFERENCE를 참조한다.

## 검증

관련98건 회귀 통과. 작은 방향 움직임도±3% 없이 판정, 기준 체결가/목표필드null, 전일거래량/목표상한 비필수, 원본 신선도·미래배제·기존 API·수동선택/UI경쟁·조회4회와전일조회0회·전역동시제한 검증. JS문법 검사 통과. 이는 예측 정확도 검증이 아니다.
