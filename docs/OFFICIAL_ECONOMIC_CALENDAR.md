# 공식 경제 캘린더

`/page/stock-calendar`와 홈 일정은 기존 `StockCalendar.fetchEvents`를 공유한다. 실적은 기존 Oracle 경로로 조회한다. 경제 일정은 기존 미국 FRED 파일에 출처별 공식 일정을 합쳐 표시한다. 예정일을 넘기면 공식 자료 또는 검증된 지표가 수신될 때까지 결과 확인 대기로 표시한다. 날짜만 알려진 금리 결정에는 정각을 만들지 않는다.

- 한국은행은 영문 연간 공지 PDF의 정책결정 8회와 한국어 결정 표를 대조한다. 35일 안의 일정은 한국은행 월간 행사 달력과도 대조한다. 11월 26일 주간보도계획의 10:30경 자료 배포, 11:10 기자간담회, 13:30 경제전망 공개, 14:00 경제전망 설명회는 원문에 근거해 표시한다. 결정문 링크가 생기면 발표 완료로 바뀐다.
- 연준과 BOJ는 연간표에서 회의 마지막 날을 사용한다. ECB는 공식 미래 일정의 통화정책회의 둘째 날을 읽고 이미 수집한 과거 날짜를 보존한다. FOMC는 뉴욕 시간, ECB는 프랑크푸르트 시간에서 KST로 변환한다.
- BEA의 GDP/PCE, BLS의 CPI/PPI/고용/JOLTS, 한국은행 GDP 속보, 국가데이터처 이번 달과 다음 달 CPI/고용을 확인한다. 공식 미국 연간 범위 검증이 통과하면 해당 기관의 일정으로 기존 같은 지표를 대체한다. 첫 수집이 실패하면 기존 FRED 일정을 계속 사용한다.
- NYSE는 연간 휴장과 정규장 조기 마감을 읽는다. Nasdaq과 일자가 확인되는 항목은 양쪽을 표시한다. 휴장은 거래소 현지일, 조기 마감 시각은 KST로 표기한다. KRX는 기존 공통 휴장표를 재사용한다.
- 현재 관세청 수출입, Eurostat, 중국 LPR/PMI/GDP, KRX/CME 파생 만기는 자동 수집 범위 밖이다. 출처별 데이터 제공 범위와 파서 검증이 필요하다.

GitHub Actions는 현재·다음 해를 매일 06:18와 13:18 KST에 갱신한다. HTTP 오류는 재시도 후 출처별 경고를 남기며, 검증 실패한 그룹의 기존 행을 보존한다. Pages 게시가 늦어질 수 있다. 수동 갱신은 `Refresh official economic calendar`를 실행한다.
