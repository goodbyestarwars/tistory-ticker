**2026-10-22 차트를 왼쪽으로 끌어 마지막 봉 뒤 빈 공간 보기**

사용자 요청. 공통 휠·관성 코드(`installSmoothWheelZoom`)가 화면 오른쪽 한도를 마지막 봉 뒤 12봉으로 고정해, 휠 가로 이동과 드래그 관성이 그보다 더 간 빈 공간을 되돌려 놓던 것을 보이는 폭의 75%(마지막 봉이 화면 왼쪽 1/4까지)로 늘리고, 이미 한도를 넘겨 끌어 둔 위치에서는 관성이 되돌리지 않고 그대로 멈추게 함. 라이브러리 드래그 자체는 제한이 없음(`fixRightEdge` 미설정). 검증: `test/test_chart_smooth_wheel.js`에 빈 공간 케이스 2건 추가 통과, 기존 차트 테스트 통과. 로컬 창이 숨김 상태라 실제 드래그 화면은 확인하지 못함.
