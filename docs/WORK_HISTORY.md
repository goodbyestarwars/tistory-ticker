## 기록 규칙

- 작업을 수행한 AI 또는 개발자가 별도 요청 없이 기록한다.
- 날짜(KST), 목적, 주요 변경, 검증·배포 결과를 간결하게 남긴다.
- 사소한 문구 수정, 단순 색상 조정, 반복된 후속 수정은 기록하지 않는다.
- 같은 작업의 후속 변경은 기존 항목에 합치거나 바로 아래에 추가한다.
- API 키, 토큰, 계정정보, 응답 원문 등 민감정보는 기록하지 않는다.
