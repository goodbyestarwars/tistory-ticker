## 현재 기준선

- 5개 메뉴의 기본 후보는 기존 숫자 검색 결과의 재정렬이 아니라 전체 저장 일봉의 OHLCV 모양에서 선정한다. 공통 엔진은 `auto-wave.selectShapesOf`, 배치는 `shape_scan.js/py`다.
- 최신 선정 정책은 `chart-first-v2`: 준비 구간 → 첫 구조 변화 → 현재 위치를 먼저 확인한다. 거래량과 상대강도는 보조 근거다.
- `groups`는 준비/첫 전환, `extended`는 추격·확장, `research`는 별도 연구다. 이전 연구 태그의 기본 메뉴 우선 표시와 상대강도 관문 정책은 최신 분리 정책으로 대체됐다.
- 기본 후보는 관찰 전용이며 `orderAuthorized=false`다. 기존 확정 신호·A/B·주문 피드·원래 `patterns`·과거 추적은 별도 계약을 유지한다.
- 새 기본 후보의 추적은 `pattern:shape-v2:<group>`에 쌓는다. `pattern:shape:*`, `pattern:edge:*`와 섞지 않는다.
- 자료 기준일·종목 유형·유동성·장기 재무 관문과 결측/지연 표시는 유지한다. 화면의 모양 점수·사후 고가 도달폭을 체결 수익이나 수익성 입증으로 바꾸지 않는다.

이번 정리에서 위 버전/관찰 경계/추적 접두사는 현재 master 코드와 대조했다. 과거 테스트·서버 운영·실시간 탐지 성능을 다시 검증한 작업은 아니다.

## 앞으로 수정할 때 반드시 남길 항목

다음 형식으로 새 기록을 추가하고 결과가 확인되면 같은 ID의 상태를 갱신한다. 미완료를 완료로 덮지 않고 보완 날짜/근거를 남긴다.

```text
ID / 날짜(KST) / 대상 메뉴 / 정책·추적 버전:
문제와 관찰 사례:
이전 → 이후 판정/표시/조회 차이:
변경 파일 / 커밋 / 원본 명세:
검증: 입력 기준일·유니버스·제외 조건 / 데이터·코드 버전 / 표본 수
전후 비교: 후보 수·공통/추가/제외 / 오탐·누락 사례 / 지연·결측
성과: 평가 지평·성숙 표본·기준가·MFE/MAE·비용 가정 / 미측정 항목
배포: master / Pages / VM / 스냅샷 기준일·계산 버전 / 운영 확인 시각
보존·롤백: 기존 API/이력/캐시 영향 / 되돌릴 커밋
결론: 유지·수정·보류 / 이유 / 다음 확인 항목
```

- 상태는 코드 반영 / 로컬 검증 / 배포 / 운영 확인 / 성과 관측을 각각 표시한다. 문서 작성·테스트 통과·배포 완료만으로 성능 개선을 확정하지 않는다.
- 전후 비교는 같은 데이터·기준일·유니버스·시장 국면·평가 지평으로 한다. 봉 당시까지의 자료만 사용하고 미완성 봉·미성숙 표본·누락·재무 미확인은 따로 집계한다.
- 후보 수가 늘거나 특정 종목을 잡았다는 이유만으로 개선으로 판정하지 않는다. 추가 후보의 오탐과 빠진 후보의 누락을 함께 확인한다. 고가 도달 가능폭·포착 종가 대비 변화·실체결 수익은 구분한다.
- 보조 관문을 바꿀 때 원인별 탈락 퍼널을 남긴다. 같은 변경에서 여러 임계값을 한꺼번에 튜닝하면 기여도를 구분할 수 없으므로 비교 가능한 단위로 기록한다.
- 과거 네임스페이스/연구 표본을 새 버전 통계에 합치거나, 운영에 없던 후보·성과 이력을 생성하지 않는다. 이 문서 복원은 운영 DB 백필·주문 변경 승인이 아니다.
- 구조·규칙 변경은 CLAUDE와 해당 원본 명세를 함께 갱신하고, 전체 변경 요약은 WORK_HISTORY에 같은 커밋으로 남긴다. 오래된 원문은 삭제하지 않고 색인 링크로 보존한다.
