## 5. 수동 반영이 필요한 영역

- `skin.html`은 저장소에 반영되어도 Tistory 관리자 스킨 편집 화면과 자동 동기화되지 않는다. 실제 Tistory 스킨 HTML을 바꿀 때는 관리자 화면에 수동 붙여넣기가 필요하다.
- `gas/ticker-proxy.gs`를 수정한 작업은 Apps Script 편집기에서 새 버전 배포가 필요하다. 이번 차트검색 빈 캐시 수정은 프론트 `js/pattern-scan.js` 변경이라 GAS 재배포는 필요하지 않다.
- GitHub Pages 정적 `js/`, `css/`, `style.css`는 `master` push 후 반영된다.
- `scripts/cloud-vm/` 변경은 VM 배포 절차와 health 확인이 필요하다.
