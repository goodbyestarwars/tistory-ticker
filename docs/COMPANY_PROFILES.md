# 종목분석 회사 소개

`data/company-profiles.js`의 `window.COMPANY_PROFILES`를 선택 종목의 요약·상세 화면에서 읽는다. 네이버 증권/WISEreport 기업개요 중 회사가 하는 사업을 설명하는 짧은 문단을 가져온 자료다. 기업 설립 이력과 최신 실적 수치보다 사업 내용을 우선한다. 소개는 25단어·180자 이내이며 출처 링크와 수집 기준일을 함께 표시한다.

기업 사업·회사명은 합병, 사업 양수도, 신사업 등으로 바뀔 수 있다. 매 방문 시 조회할 필요는 없어 사용자 요청대로 **한 번 수집한 정적 자료**를 사용한다. 신규 상장이나 중요한 사업 변경 때 아래 스크립트를 PC에서 다시 실행해 갱신한다. 자동 수집 타이머·VM API·DB는 추가하지 않는다.

```powershell
python -X utf8 scripts/build_company_profiles.py
```

기존 작업의 끊긴 수집만 이어서 하려면 `--resume`, 누락 자료도 재시도하려면 `--resume --retry-missing`을 사용한다. 재수집 후 생성된 데이터 파일을 master에 반영하면 GitHub Pages에서 배포된다. 최대 2개 연결, 요청 간격 0.15초, 응답 512KB·타임아웃 5초 제한. 임시 체크포인트는 비추적 `work/company-profiles-checkpoint.json`에 보관한다.

우선주는 보통주와 같은 회사 소개와 출처 코드를 공유한다. ETF·ETN·스팩은 일반 회사 수집 대상에서 제외한다. ETF의 기존 상품 소개는 유지한다. 일부 기업은 출처에 사업 설명이 없거나 수집 실패일 수 있다. 없는 소개는 생성하지 않고 WICS 업종(있을 때)과 기업개요 링크로 안내한다. 데이터의 `covered`·`missing`으로 소개 커버리지를 확인할 수 있다.

브라우저는 선택한 종목에서 처음 소개를 보여줄 때 정적 파일 한 번만 로드한다. 같은 페이지에서 목록 선택·상세 조회는 자료를 공유하며 진행 중 로드도 합친다. 종목 변경 뒤 도착한 응답은 버린다. 소개 로드 실패는 수급·차트·스윙 판정 표시를 막지 않는다.

`asOf`는 수집일이며 기업의 공시일이나 사업변경일을 의미하지 않는다.

최초 수집(2026-10-07): 회사 2,588개·우선주 포함 종목 코드 2,696개 중 소개 2,631종목 확보, 소개 없는 65종목은 업종/원문 링크 안내. 회사 소개 정적 파일의 갱신은 VM 재시작·검색 재스캔 조건에서 제외한다.
