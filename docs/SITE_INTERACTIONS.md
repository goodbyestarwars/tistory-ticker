# 공통 포인터와 뉴스 캐러셀

2026-10-09. 기존 스킨 공통 엔트리 `js/skin-shell.js`가 `js/site-interactions.js`를 단일 Promise로 로드한다. 새 Tistory 마크업이나 수동 스킨 반영은 필요 없다. 이전 자산이 브라우저 캐시에 섞여 있어도 홈/리포트가 의존성 없음으로 중단되지 않게 보호한다.

## 적용 범위

공통 스킨을 사용하는 홈/휴장·증시온도·국내 주요종목·종목분석·종목검색/실시간 차트·차트검색·전략검색·DCF·시장지표·뉴스·캘린더·MY·일반 글과 내부 페이지에 동일 모듈을 로드한다.

공통 스킨이 없는 `dcf/index.html`, `learn/*.html`, `legal/*.html`, `release-notes.html`에는 같은 파일을 직접 연결했다. 개발용 `docs/architecture.html`과 기존 테스트 페이지는 운영 적용 대상에서 제외한다. 코드 복제 없이 하나의 모듈만 사용한다.

## 포인터 동작과 제외

기존 빨간색16점 곡선 SVG·40px 기준/20~96px 휠 조절·프레임 간 추종식을 유지한다. SVG는 페이지당 하나, 스크립트 중복 로드도 이벤트 등록 전에 반환한다. 마우스 왼쪽 누름 중에만 RAF를 돌리며 이동 이벤트는 활성 상태에서만 처리한다. 프레임에서 레이아웃을 읽지 않는다.

캔버스/iframe·실제 `.ss-chart`, `.ss-lw-chart-root`, `.dmi-chart`, `.ff-chart`, `.kf-chart` 및 chart 계열 영역·`.de-chart-overlay/.de-chart-modal`·그리기 레이어/도구·carousel/slider 영역·`.learn-card-grid`·입력/편집/버튼·`role=slider/scrollbar`·`data-drag-ready`·`draggable=true`·`data-no-pointer-effect` 영역을 제외한다. 일반/내부 스크롤바와 활성 텍스트 선택도 감지한다. 새 조작 컴포넌트는 `data-no-pointer-effect`를 사용할 수 있다.

일반 영역에서 시작해 제외 영역에 들어가면 종료하며 새 누름 전에는 재시작하지 않는다. 캡처 단계에서 실제 hover 요소를 확인해 위젯의 포인터 캡처나 전파 중단에도 종료한다. 차트의 pointer/mouse/wheel 기본 이벤트를 막지 않는다. 효과가 실제 활성인 일반 영역의 휠만 크기 조절에 사용한다.

pointerup/cancel, 버튼 유실, 창 이탈, blur, pagehide, 페이지 숨김, 텍스트 선택, 미디어 설정 변경에서 path와 RAF를 지운다. 터치/펜 입력을 거부하고 coarse pointer/hover 없음 및 reduced-motion에서 시작하지 않는다.

## 공유 캐러셀

홈 브리핑과 휴장 시장뉴스가 동일 `SiteInteractions.carousel(section, options)`를 호출한다. 브리핑의 기존 진행 슬라이더는 유지한다. 뉴스는 공급받은 timeline 순서와 기존20건 상한, 뉴스/공시 필터를 유지하고, 기존 접힌 행의 더보기 대신 모든 카드를 페이지 이동으로 볼 수 있다. API·정렬·캐시·수집은 바꾸지 않는다.

뉴스 카드는 콘텐츠 가용 폭960px 이상3개·620px 이상2개·그 미만1개다. 260px 동일 높이, 제목3줄/요약2줄, 언론사·발행일시·시장·공시 구분과 기존 주가변동 표시를 보존한다. 제목 링크가 아닌 카드 전체가 원문 링크이며 새 탭 원문 열기는 기존 동작을 유지한다. 밑줄은 기본/방문/hover에서 제거하고 focus 윤곽은 유지한다.

좌우 버튼/키보드/6px 초과 마우스 드래그/브라우저 네이티브 터치 스와이프, 실제 가용 폭에 따른 페이지 수, 부분 마지막 페이지, 끝 버튼 비활성화를 지원한다. 자동 넘김은 없다. 드래그한 클릭만 막으며 다음 일반 클릭은 허용한다. scroll/resize 갱신은 하나의 RAF로 합친다. 보고서 DOM을 교체/제거할 때 destroy로 ResizeObserver/MutationObserver·전역 종료 리스너·프레임/클릭 타이머를 정리한다.

## 휴장 캘린더

`.home-closed-status`를 말풍선 전체 `<a href="/page/stock-calendar" aria-label="캘린더">`로 변경했다. 기존 메뉴와 같은 URL이고 target 없이 동일 탭 이동한다. 말풍선 배경/꼬리/위치/안내문을 보존하고 표시 링크는 ‘캘린더 →’다. 키보드 접근성과 focus-visible 윤곽을 제공한다. 시장 시간·휴장 판정은 변경하지 않았다.

## 검증과 경계

`test/test_site_interactions.js`: 단일 초기화/RAF/종료/제외/재시작/휠/터치·펜·reduced-motion/선택/0·1카드/부분 마지막 페이지/오클릭/수명주기11건. 주간리포트 CSS8건 통과. 기존 UI175건에서 변경전14실패와 변경후14실패가 동일하며 신규 실패는 없다. 과거 UI 계약과 현재 구현의 기존 불일치는 이 요청에서 변경하지 않는다.

`test/site-interactions.html`은 실제 공통 모듈과 실제 뉴스 마크업 생성 함수를 사용하고 테스트 뉴스만 제공한다. 실제 브라우저에서 1920/1280px 3카드, 800px 2카드, 390px 1카드/가로 넘침 없음, 드래그·터치·포인터 종료를 확인한다. 운영 차트·휴장 및 대표 내부 페이지는 배포 후 추가 확인한다.

모든 변경은 정적 자산과 브라우저 입력 처리다. 신규 VM API/타이머/프로세스·GAS 요청·뉴스 수집은 없다. 주간 리포트의 기존 데이터 요청과 차트 호출 경로는 그대로다.
