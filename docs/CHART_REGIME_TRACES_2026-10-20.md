# 차트 추세 상태 띠·거래량/가격 흔적 (2026-10-20)

## 표시 계약

차트검색과 종목분석은 공통 chart-core.js를 쓴다. 추세 화살표와 반복 글자는 제품에서 제거하고 상단에 단기/중기/장기 상태 띠 및 현재 상태를 표시한다. 빨강=상승, 파랑=하락, 회색=전환·중립, 자료 부족은 별도 표기. 십자선이 있는 날의 상태와 날짜를 표시하며, 차트 밖으로 나가면 최신 봉으로 돌아간다. 과거 띠와 최신 상태를 혼동하지 않게 날짜를 함께 쓴다.

|기간|정배열/역배열|기울기|최초 확인에 필요한 유효 봉|
|---|---|---|---:|
|단기|SMA5 > 10 > 20 / 반대|SMA20의5봉 변화율 ≥+0.2% / ≤-0.2%|27|
|중기|SMA20 > 60 > 120 / 반대|SMA60의10봉 변화율 ≥+0.2% / ≤-0.2%|122|
|장기|SMA60 > 120 > 224 / 반대|SMA120의20봉 변화율 ≥+0.2% / ≤-0.2%|226|

배열과 기울기가 함께 맞을 때 상승/하락, 나머지는 전환·중립이다. **새 원 상태가 연속3봉일 때 세 번째 봉부터** 표시 상태를 바꾼다. 그 전까지 이전 확인 상태를 유지하며 확인 중1/3·2/3을 표시한다. 일봉은 일봉 수, 주봉은 주봉 수, 월봉은 월봉 수 기준이며 주/月에 일봉 기준을 적용하지 않는다. 데이터가 없거나 잘못되면 확정 상태를 추정하지 않고 자료 부족으로 돌린다. 현재 진행 중인 봉은 잠정이며 종가 확정 전 결과가 달라질 수 있다. 수익 최적화한 기울기값이 아니며 매매 판정과 연결하지 않는다.

상태 띠는 보이는 시간 범위에 맞춰 그린다. 상단 현재 상태/MA 범례 높이를 측정해 캔들 가격축 여백을 확보하고, 껐을 때 원래 여백을 복원한다. 확대·축소·리사이즈·재렌더 때 구독과 관찰자를 정리한다. 운영 모바일에서 기존 최소 봉 간격0.5px 때문에 5년 버튼을 눌러도 약2년만 들어가던 문제를 확인해 공통 두 프로필을0.1px로 낮췄다. 종목분석은 자동 크기 변경 때도 선택 기간을 고정해 가격축 폭 변화로 기간이 잘리지 않게 한다. 1/3/5년의 실제 보이는 날짜 범위가 요청 기간의97% 이상인지 검사한다.

## 흔적과 기본 모드

- 기본: 추세 ON, 거래량·가격 흔적 ON + 중요 모드. **현재 검증 통과 유형은0개**이며 선택창에 이를 명시한다. 3배 거래량 또는 ±2% 접근을 중요 신호로 승격시키지 않는다.
- 상세 모드: 기존 원 관측을 모두 유지한다. ● 거래량, ■ 장기선, 작은 ▲ 회복. 날짜당 대표 하나, 회복 → 실제 장기선 공방 → 거래량 → 단순 접근 순이다. 캔들 마커의 text는 항상 빈 문자열이다. 모든 겹친 조건·배수·대용 거래대금·양/음봉·윗꼬리·기준봉·장기선 값/거리/동작은 십자선 툴팁에서 확인한다.
- 상세 축소 화면은 약16px에 하나로 덜어내고 확대하면 다시 나타난다. 이는 표시 밀도 조절이며 신호 날짜/데이터/확인을 옮기지 않는다. 감춘 날짜도 상세 모드 십자선으로 볼 수 있다.
- 단순 접근은 상세 원 관측에서만 유지한다. 사용자에게 매집·세력 매수·상승 예측으로 표현하지 않는다. 이후 회복이 확인되면 원래처럼 회복 발생일에만 남는다.
- 국내 일봉 흔적 범위는 유지한다. 미국/주봉/월봉/분봉에 국내 일봉 흔적을 가짜로 이식하지 않는다. 추세 띠는 해당 입력 봉 단위로 표시한다. 기존 accumulation*·trendStates/Markers/Summary 등 비교용 함수와 원시 캐시/이력은 보존한다.

## 과거 자료 검증

기존 Naver 연구 캐시2,618파일 중21봉 이상2,617종목, 2020-01-02~2026-10-16의 유효 조사 구간3,841,036종목일(첫20봉 평균 준비 제외)을 재사용했다. 새 시세 수집/API 호출은 없다. 원 파일은 수정하지 않았다.

학습2020~2023 / 검증2024~2026-10-16, 학습 결과가2024로 넘어가는 보유기간은 제거했다. 같은 종목·유형은20봉 간격으로 남기며 60봉 결과의 잔여 중복은 있다. 신호 다음 봉 시가 진입,20/60봉 종가 청산, 왕복비용0.5% 가정의 순수익 및 보유 중 최저가 기준MAE/최고가 기준MFE를 계산했다. 표의 MAE는 **각 사건 최대 하락폭의 평균**이다. 성공·수익을 현재 봉의 필터로 사용하지 않았다.

한계: 현재 확보 캐시의 생존편향, 과거 시총/관리종목/상장폐지 상태 미확인, 분할·배당 조정의 독립 대조 미실시,60봉 잔여 중복, 전체 종목일/유동성 기준선은 시총·변동성·시장 국면을 정밀 매칭한 인과 대조군이 아님. 종목별 부트스트랩·다중검정 보정까지 통과한 통계적 유의성은 주장하지 않는다. 이 자료로 수급 주체나 매집 여부를 식별할 수 없다.

재현: `node scripts/research/study_chart_trace_ui.js <기존캐시/naver> <새결과경로.json>`. 원 파일을 읽고 집계 JSON만 쓴다. 결과 JSON에는 연도별 표본·평균/중앙값/p10·승률·MFE·MAE·거래대금 대용 통계가 있다.

## 검증 및 배포

- 새로운 상태 띠: 배열+기울기,3봉 확인, 작은 기울기 중립, 데이터 결측, 매 접두 구간과 전체 계산의 일치(미래 비참조), 자료 부족, 봉 단위.
- 마커: 기본 중요 유형 없음, 상세1기호/날짜, 겹침 상세 유지, 줌 밀도, 기존 이벤트/플러그인 보존, 토글·리스너 정리.
- 기존 추세/누적거래18개·수급 원 판정9개와 관련 차트 상호작용/기간/줌/작도 회귀 유지.
- 실제 두 렌더러+기존 저장 OHLCV: PC1440/모바일390,1/3/5년, 일/주/월, 반복 렌더·마우스/터치 툴팁·모드/추세 토글36조합 확인. 스크린샷은 실제 일봉을 사용한 로컬 렌더러 QA이며 운영 캡처와 구분한다.
- 기존 test_chart_core.js는 골든3 vs종전0.5 불일치로 이미 실패했다. 이번 명시적 5년 축소 수정에 맞춰 테스트가 이번 최소간격0.1과 종목분석 크기변경 시 기간유지 옵션만 새로 기대하도록 선언하고, 원 골든 파일은 보존했다. 실제 라이브러리에 있는 LineStyle.Solid가 빠진 테스트 모의객체도 보완해 공통 엔진 전체 검사가 통과했다.

수정 범위: 공통 chart-core.js, stock-search.js, foreign-flow.js, 두 화면 CSS, 연구 스크립트, 관련 테스트/문서. 자동매매 A/B 판정·주문·예산·서버/DB/GAS/스킨 수정은 없다. 사용자 지시에 따라 테스트 후 master 및 GitHub Pages 배포, 운영 파일/두 화면을 확인한다. 최종 배포 SHA와 운영 캡처는 작업 출력 보고서에 기록한다.
