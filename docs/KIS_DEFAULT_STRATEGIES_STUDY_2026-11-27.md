# KIS Strategy Builder 기본 전략 일봉 백테스트 (2026-11-27)

연구 전용. 주문·자동매매·검색기 정책과 연결하지 않는다. 기준은 결과를 보기 전에 고정했다.

## 대상 (9개 고유 전략, 사용자가 붙여넣은 기본 파일 10개 중 중복 제외)

| 키 | 매수 신호(t일 종가) | 매도 신호 |
|---|---|---|
| goldenCross | SMA5가 SMA20을 상향 교차 | 하향 교차 |
| momentum | 60일 ROC > 30% | ROC < -20% |
| high52w | 종가 > 직전 252일 고가 최대(오늘 제외) | 종가 < 그 값 |
| consecutive | 5일 연속 상승 | 5일 연속 하락 |
| disparity | 20일 이격도 < 90 | > 110 |
| breakoutFail | 종가 < 직전 20일 고가 최대(오늘 제외) | 종가 > 그 값 |
| strongClose | IBS=(종-저)/(고-저) ≥ 0.8 | IBS < 0.5 |
| volatility | 10일 수익률 표준편차 < 2% 이고 당일 +3% 이상 | 당일 -3% 이하 |
| meanReversion | 5일 이격도 ≤ 97 | ≥ 103 |

## 체결·청산 (고정)

- 신호 다음 날 시가 진입, 매도 신호 다음 날 시가 청산, 진입가 -5% 손절(저가 터치 시 손절가, 갭하락 시 시가), 최대 60거래일(종가), 종목당 동시 1포지션.
- 비용 왕복 0.7%. 거래대금(종가×거래량) 5억 이상, 상장 260봉 이상인 날만 신호 인정.
- 아직 끝나지 않은 마지막 포지션은 집계하지 않는다.

## 판정 (고정)

- 분할: 진입일 20240901 전/후. 각 구간 n ≥ 100.
- 신호 있음: 두 구간 모두 평균 > 0, 일자 군집 부트스트랩 CI95 하한 > 0, 상위 5건 제외 평균 > 0.
- 한 구간이라도 n < 100이면 판정 불가, 그 외 신호 없음.

## 한계

- KIS 도구의 체결·수수료·정확한 정의와 다를 수 있다(52주 신고가·돌파 실패의 매도 조건은 구조상 거의 항상 성립해 사실상 1일 보유가 된다).
- 일봉 5년 Oracle 캐시, 생존 편향 가능. 통계는 `closing_bet_formula_study`를 재사용.
