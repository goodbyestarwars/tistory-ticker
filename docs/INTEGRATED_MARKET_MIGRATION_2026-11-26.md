# 국내 종목 통합시장 전환 검증 (2026-11-26)

사용자 결정: 국내 종목 현재가·호가·체결·분봉·일봉·검색기·백테스트를 KRX+NXT 통합시장 기준으로 정렬한다. KOSPI/KOSDAQ 공식 지수 및 KRX/NXT 고유 시장통계는 공급자가 정의한 지표 그대로 유지한다. 실계좌 주문 설정·재시작은 이 작업에 포함하지 않는다.

## 1단계 — 검증용 조회 계약

키움 공식 ka10081 명세: https://openapi.kiwoom.com/m/guide/apiguide/07/ka10081
기존 공통 fetch_daily_ohlc / fetch_minute_ohlc에 명시적 market=UN을 추가한다. KRX는 6자리, NXT는 _NX, 통합(SOR)은 _AL. 기본 호출은 그대로이며 공급자 장애에 다른 시장 값을 섞지 않는다.

Oracle의 기존 인증 환경으로 NXT 대상 376900 및 대상이 아닌 종목, ETF, 신규상장·거래정지 등 표본에서 각 시장 응답의 실제 거래일·OHLCV·과거 범위·누락을 확인한다. 11/25 거래량 417576 vs 364240은 제보값이지 실제 통합 API 실측값이 아니다. 장전 08시, 정규장 09시, NXT 종료 20시 이후 확정 확인을 분리한다. 모의투자 API는 KRX만 지원하므로 운영 API로 검증한다. 공식 거래일과 세션 경계를 적용한다.

## 2단계 — 데이터 격리 및 전환 게이트 (미구현)

- daily_prices와 chart_daily_prices의 현재 PK(code,date)는 시장을 구분하지 않는다. 기존 시계열을 보존하고 통합 시계열을 별도 저장 또는 시장 키를 포함한 새 스키마로 전체 백필한다. 출처, 시장, 조회/확정시각, 데이터 범위를 기록한다. 일부 행만 통합으로 덮어쓰지 않는다.
- 동일 거래일의 KRX/NXT/통합 거래량 대조, 유효 OHLC, 권리수정, 비대상 종목, 장전/장후 최종치, 누락 및 전체 표본 커버리지 검증. 검증 실패는 이전 시장을 통합으로 표시하지 않는다.
- 차트/요약/주·월봉/분봉의 캐시 시장 키, 프런트의 정규장 필터, 08~20시 장중 갱신 및 장 종료 후 최종 확인을 함께 변경한다.
- REST 시세 및 WS의 UN 원천 증거를 확인하고 혼합·지연·미확인 폴백을 통합값으로 표시하지 않는다. 수급 확정 및 원천시세 접근 경계를 유지한다.
- scan_inputs, daily_scan, shape_scan 및 기타 일봉 소비자와 backtest 입력을 같은 검증된 통합 스냅샷으로 변경한다. 과거 KRX 성과와 새 통합 성과, 비교 기간·표본·비용·MDD를 분리한다. 확정 신호와 실주문 피드는 별도 검증/승인 전 기존 정책을 보존한다.
- 실제 서버 API 검증, DB 백필/완전성 검사, 전체 회귀, 배포 이후 실응답 확인 후 전환한다. 현재는 미실시이며 이 브랜치를 병합한다고 운영 전체가 전환되는 것은 아니다.
