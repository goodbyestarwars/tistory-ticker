# 시장지표 5년 차트

시장 > 시장지표의 국내 현물·주간선물, 글로벌 지표, BTC/ETH, 주요 미국 발표를 최근 5년의 관측 이력으로 표시한다. 일봉에서 주봉은 브라우저가 계산한다. 가격 카드의 차트와 미국 발표 차트는 같은 230px·축·폰트 규칙을 쓴다. 개별 종목 차트와 분봉의 조회 범위는 이 변경에 포함하지 않는다.

## 데이터와 부하

`data/chart-history/{domestic,global,crypto,macro}.js`는 `window.MARKET_HISTORY_ARCHIVES[group]`에 저장된 읽기 전용 자료다. `js/market-history.js`가 탭별 1회 요청을 공유하고 기존 VM의 최근 자료와 날짜 기준으로 합친다. 중복 날짜는 최신 VM 자료가 우선하고 5년보다 오래된 자료는 제외한다. 과거 이력 로드 실패 시 기존 최근 차트가 유지된다.

| 파일 | 지표 수 | 원본 바이트 | gzip 바이트 |
|---|---:|---:|---:|
| 국내 | 3 | 152,749 | 52,596 |
| 글로벌 | 15 | 379,774 | 101,005 |
| 가상자산 | 2 | 86,703 | 19,845 |
| 미국 발표 | 10 | 11,516 | 3,108 |
| 합계 | 30 | 630,742 | 176,554 |

2026-10-08 최초 실측. gzip은 별도 계산값이며 실제 CDN 압축 방식/헤더에 따라 전송량은 달라진다. 전 탭 자료를 한꺼번에 받지 않는다. JS 배열은 방문자의 브라우저에서 해석하므로 VM 런타임 메모리와 SQLite에는 5년 자료를 추가하지 않는다. VM의 저장소 pull에는 정적 파일 및 Git 객체만 작은 용량으로 추가될 수 있다.

`scripts/build_market_history.py`는 PC 또는 GitHub Actions에서만 실행한다. 최초 수집 후 코인·환율·국고채는 최근 페이지만 갱신하고, 네이버 차트와 FRED는 각 1회 요청으로 수정치를 포함한 5년 자료를 다시 확인한다. 실패한 공급자의 기존 자료는 보존한다. 워크플로는 실패한 수집본을 배포하지 않는다.

`.github/workflows/market-chart-history.yml`는 토요일 09:15 KST에 공개 저장소의 표준 GitHub 러너에서 갱신한다. VM에서는 실행하지 않으며 새 VM 타이머/프로세스/DB가 없다. `deploy_check.sh`의 VM 재시작 및 전 종목 재검색 감지에서 `data/chart-history/`를 제외했다. 수동 실행은 Actions의 Market chart history 또는 `python scripts/build_market_history.py`를 사용한다. 표준 공개 저장소 러너는 [GitHub 공식 안내](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)에 따라 무료다.

## 출처와 실제 범위

- 국내 지수/주간선물 및 미국 지수/연결선물: 기존과 같은 네이버 차트. 연결선물은 만기 교체가 포함된다.
- 환율: 기존 네이버 FX_USDKRW 종가.
- 국고채3년: 폐쇄된 IRR_GOVT03Y HTML(HTTP 410)을 네이버 KFIA103000 JSON으로 교체. 기존 저장본 49일 대조에서 차이는 최대 0.01%p. 400관측치 조회가 최대58회에서7회로 줄었고 6시간 수집 주기는 유지한다.
- 미국채 및 경제 발표: 기존 FRED 시리즈. 월/분기 자료를 일별 값으로 복제하지 않는다. 수정 발표값이 반영되는 최신 통계 이력이다.
- BTC/ETH: 기존 업비트 KRW 일봉, KST 날짜 표시. [Upbit 일 캔들](https://docs.upbit.com/kr/reference/list-candles-days)의 200개 제한에 맞춰 UTC `to`로 페이지를 잇는다.
- 국내주식 토큰: 기존 바이낸스 무기한선물의 브라우저 조회. 최대 5년 일봉을 필요한 페이지만 받고 1시간 캐시, 동시3종목 제한. 평균은 완료한 365/180개 연속 일봉으로만 계산한다.

야간선물 및 신규 토큰은 확보된 짧은 이력을 그대로 표시하고 실제 시작/종료 월을 붙인다. 주간선물로 야간 과거를 만들거나 상장 전 데이터를 채우지 않는다. 분봉은 거래/그리기용 최근 구간을 유지한다. 미국 발표 카드의 평균은 기존 최근12회 기준을 유지하고 시장 탭의 차트만 5년으로 확장한다. 캘린더 결과 카드의 기존 미니차트는 유지한다.
