### VM 접속 (2026-09-17 변경)
이제 **이 PC에서 직접 VM 명령을 실행할 수 있다.** 사용자가 gcloud CLI를 설치하고 로그인했다.
- 실행은 **PowerShell**로 한다(Git Bash는 경로 공백 때문에 실패).
- 경로: `$env:LOCALAPPDATA\Google\Cloud SDK\google-cloud-sdk\bin\gcloud.cmd`
- 예시:
  ```powershell
  $gc = "$env:LOCALAPPDATA\Google\Cloud SDK\google-cloud-sdk\bin\gcloud.cmd"
  & $gc compute ssh instance-20260712-153038 --zone us-central1-c --strict-host-key-checking=no --quiet --command 'uptime; free -m'
  ```
- **함정**
  - 원격 명령 문자열에 **큰따옴표를 넣지 말 것**(cmd가 인자를 쪼갠다). PowerShell 쪽은 작은따옴표로 감싼다.
  - `$(...)`·`%{...}` 같은 표현도 PowerShell/cmd가 가로챈다. 필요하면 파일로 만들어 실행.
  - 윈도우 gcloud는 plink를 쓰므로 `-- -o ...` 같은 OpenSSH 옵션이 안 먹는다.
  - 서버가 눌려 있으면 SSH가 255로 끊긴다. 몇 번 재시도하면 붙는다.
  - **로그인 사용자가 `goodb`다**(앱 계정 `goodbyestarwars`가 아니다). `~/kiwoom-api` 아래를 보려면
    `sudo`를 붙여야 한다. 예: `sudo cat /home/goodbyestarwars/kiwoom-api/.last_deployed_sha`,
    `sudo tail -5 /home/goodbyestarwars/kiwoom-api/deploy.log`
  - 프로세스 종료·서비스 재시작도 `sudo`로 가능하다(2026-09-17 장애 때 사용).
- Cloud Shell은 VM이 아니다(메모리 16GB짜리 별도 컨테이너). VM 상태를 보려면 위 SSH로 들어가야 한다.
