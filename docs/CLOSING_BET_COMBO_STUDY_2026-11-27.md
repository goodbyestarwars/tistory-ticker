# 종가배팅 검색식 "좋은 조건만 뽑기" 구간 분할 검증 v2 (2026-11-27)

연구 전용. 주문·자동매매·검색기·공개 API와 연결하지 않는다. **아래 기준은 결과를 보기 전에 고정한다.** 바꾸려면 새 버전 문서를 만든다. 전 단계 결과: `docs/CLOSING_BET_FORMULA_STUDY_2026-11-27.md`(식 전체 신호 없음, 한 조건씩 빼도 동일).

## 목적

사용자(2026-11-27 "좋은것만 뽑아봐", 앞서 "거래량은 기본으로")는 식 전체를 쓰지 않고 좋은 조건만 남기길 원한다. 사후에 좋아 보이는 조합을 고르면 우연을 뽑기 쉬우므로 **앞 구간에서 고르고 뒤 구간에서 확인**한다.

## 후보 (거래량 A 고정)

- A(40일 중 거래량 전일 3배 3회 이상)는 항상 켠다. 거래 가능 관문·겹침 제거·청산·비용은 v1과 동일하다(종가 매수, 왕복 0.4%).
- 나머지 4개 부품을 켜고 끄는 모든 조합: **B**(20봉 고저 10%), **CD**(240일선 또는 480일선 이격 100~120%), **nE**(5<10<20 역배열 아님), **F**(등락률 −3% 이상) → 2^4 = 16개(A만 있는 조합 포함).
- 신호 정의·겹침 제거(직전 5거래일 원신호 있으면 제외)는 조합별로 따로 적용한다.

## 선택과 확인

- 기간 분할: **선택 구간** 신호일 < 2024-09-01, **확인 구간** 신호일 ≥ 2024-09-01.
- 선택: 선택 구간에서 체결 300건 이상인 조합 중 **P1(다음날 시가 매도) 비용 후 평균**이 높은 상위 3개. 청산은 P1만 쓴다(종가배팅). P2(5일 뒤 종가)는 참고로만 본다.
- 확인(주 결과 3개): 선택된 3개 조합을 확인 구간에서 평가한다. 다중 비교를 고려해 군집 부트스트랩 구간은 **99.17%**(95%를 3으로 나눈 보정)를 쓴다.

| 판정 | 기준 (모두 만족) |
|---|---|
| 좋은 조합 있음 | 확인 구간 체결 ≥ 100건 · 비용 후 평균 > 0 · 99.17% 군집 하한 > 0 · 상위 5건 제외 평균 > 0 · 같은 날 관문 통과 전종목 평균(기준선)보다 높음 |
| 판정 불가 | 확인 구간 체결 < 100건 |
| 없음 | 그 외 |

- 탐색(판정에 쓰지 않음): 16개 조합 전체의 선택·확인 구간 평균 표, 선택 구간 순위와 확인 구간 순위의 일치도(순위 상관).
- 선택 구간에서 좋았다가 확인 구간에서 무너지면 그 조합은 우연이다. 통과해도 운영 검색기·자동매매 반영은 별도 승인이며 장중/일봉 그림자 기록으로 재확인한다.

## 한계

- 약 4년 한 시장 구간의 두 쪽 분할이라 레짐 변화는 보지 못한다. 확인 구간이 짧아 군집이 적다.
- 이벤트가 같은 날 몰리고, 종가 체결·슬리피지 가정은 v1과 같이 낙관적이다.
- 후보 부품이 사용자가 가져온 식의 것으로 제한된다. 다른 좋은 조건(수급, 지지선 등)은 이 범위 밖이다.

## 상태

**결과 (2026-11-27, 기준 변경 없음): 좋은 조합 없음. 선택된 3개 모두 "없음".**

- 선택 구간(2022-09~2024-08)에서 P1 평균 상위 3개: `A+B+nE+F`(−0.12%), `A+B+nE`(−0.12%), `A+nE+F`(−0.13%). 이미 선택 구간에서 16개 조합 전부 음수(−0.12 ~ −0.22%)였다.
- 확인 구간(2024-09~2026-11) P1: `A+B+nE+F` −0.06%, `A+B+nE` −0.06%, `A+nE+F` −0.07%(기준선 −0.20%). 99.17% 군집 하한은 모두 0 아래(예: A+nE [−0.15, +0.01]). 확인 구간에서 가장 덜 나쁜 조합도 `A+B+CD+nE` −0.02%로 0을 넘지 못했다.
- 16개 조합 전부 확인 구간에서도 음수(−0.02 ~ −0.10%). 5일 보유(P2)는 −0.26 ~ −0.58%.
- 선택 구간 순위와 확인 구간 순위의 상관은 −0.23이라 선택 구간에서 좋았던 조합이 뒤에서 이어지지 않는다. 다만 조합 간 차이(수 bp)가 신호 규모에 비해 작아 순위 자체가 잡음에 가깝다.
- 거래량 조건(A) 하나만으로 이미 전체 신호의 대부분을 만든다(A 17,768건 vs 식 전체 9,136건). B·nE·F는 신호를 거의 걸러내지 못하고 평균도 바꾸지 못한다. 이평 이격(CD)은 신호를 절반으로 줄이지만 평균은 같다.
- 시장 전체의 다음날 시가 평균도 −0.20%다(종가 매수 후 시초 매도는 비용 0.4%를 넘기 어려운 구조). 이 식이 시장보다 +0.1%p 높은 것은 비용을 넘는 크기가 아니다.
- 결론: 이 식의 부품에서 "남길 좋은 조건"은 없다. 식 밖의 새 조건(수급·지지선 등)은 새 버전 문서로 사전 등록해야 한다.
