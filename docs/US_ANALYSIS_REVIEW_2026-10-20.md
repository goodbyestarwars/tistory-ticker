# 미국 애널리스트·내부자 공시·전체화면 수정

## 출처와 SAVE 화면 비교

- `stock-visa-application`은 기업 비자 신청 자료이며 추천 동향과 무관하다. 실제 기존 API는 `/stock/recommendation`이다.
- Finnhub 공식 문서의 Recommendation Trends 항목과 실제 응답을 확인했다. 기존 일반 API 문서 링크는 사용자에게 종목 원본을 직접 보여주지 못해 [INTC 종목별 공식 위젯](https://widget.finnhub.io/widgets/recommendation?symbol=INTC)으로 바꿨다. 다른 티커도 해당 심볼로 연결한다.
- 검증 당시 INTC Finnhub 최신 집계는 `2026-09-01`, strongBuy4+buy15 / hold34 / sell2+strongSell0 = **55건**이다. 고유 기관55개 또는 애널리스트55명이라고 단정하지 않는다. 강력 의견은 해당 매수·매도에 합산하고 화면에 명시한다.
- 사용자 첨부 SAVE 화면은 `Data: TIPRANKS`, `2026.10.19 갱신`, 애널리스트30명, 매수6/보유23/매도1이다. 제공처·기준일·집계 범위가 다르므로 같은 데이터로 표시하거나 SAVE 수치로 바꾸지 않는다. 두 제공처의 원자료 전체가 없어 차이 전부를 개별 대조한 것은 아니다.
- 기관별 최신 평가는 Finnhub `/stock/upgrade-downgrade`를 별도로 조회한다. INTC·AAPL 모두 기존 키에서 **HTTP403**이 확인됐다. 화면에 권한 미확보를 명시하며 기관명을 만들지 않는다. 권한이 확보된 응답에 대해서는 최근90일·최대50건의 기관명, 평가일, 이전→현재 의견과 상향/하향/유지 등을 표시하는 경로를 구현했다. 월별 집계와 합치지 않는다. 실제 기관의 매매 내역도 아니다.

## 내부자 거래 오류 수정

기존 코드는 반환된 모든 `change`를 기간·거래코드 구분 없이 합산했다. 보상·옵션 행사·세금 원천징수까지 매수·매도처럼 보일 수 있었다.

- 거래일 기준 최근90일(양 끝 포함), 조회 기준일 이후의 거래·공시 제외.
- `isDerivative=false`이며 거래코드 P만 매수, S만 매도. 수량은 절댓값이며 기타 코드를 순매수에 넣지 않는다.
- A(보상/취득), M(행사/전환), F(세금/행사가격 지급), G(증여)와 파생상품·분류 미확인 건은 기타로 구분한다. 기준은 [SEC Forms3/4/5 안내](https://www.sec.gov/files/forms-3-4-5.pdf)다.
- 이름·거래일·공시일·수량·단가·거래코드·파생 여부를 펼쳐 볼 수 있다. 통화가 미제공이면 임의 USD를 붙이지 않는다.
- 동일 접수번호/이름/거래일/코드/수량/보유수량/단가/파생 여부의 완전 중복만 제거한다. 정정공시 사이의 의미상 중복까지 검증했다고 주장하지 않는다.
- SEC 원문은 보고 기업의 실제 CIK와 접수번호로 연결한다. 접수번호 앞자리는 제출대행자 CIK일 수 있어 주소 경로로 사용하지 않는다. INTC 및 AAPL의 대표 원문 주소를 실제200 응답으로 확인했다. 보고 기업 CIK를 확보하지 못하면 원문 주소를 만들지 않는다.
- 반환자료 최신 공시일과 커버리지 한계를 표시한다. API 미확보와 반환0건을 구분한다. 거래일/공시일 누락은 집계에서 제외한다.

실제 API 재조회 당시 거래일 범위는 2026-07-22~2026-10-19였다:

|종목|비파생 P 매수|비파생 S 매도|기타|반환자료 최신 공시|
|---|---:|---:|---:|---|
|INTC|105,263주 / 1건|0주 / 0건|4건|2026-08-14|
|AAPL|0주 / 0건|281,782주 / 20건|24건|2026-10-15|

INTC 자료가 10월까지 완전하다는 뜻이 아니다. SAVE 내부자 상세 기간/분류/원자료가 첨부 화면에 없어 동일 기간의 행별 대조는 미실시다. 자료 최신성 차이까지 화면에서 확인할 수 있게 했다.

## 차트

- 미국 `usStocksChart` 내부만 모달로 이동하면 바깥 패널의 전체높이 레이아웃 규칙이 적용되지 않았다. 국내와 같이 전체 패널을 이동하고 내부 차트가 남은 높이를 사용하게 했다.
- PC1440×1000 검증: 미국 차트614px, 국내 한화오션 약614px. 모달 본문 끝과 패널 끝 간격26px. 기존 미국 화면의 큰 하단 빈 공간을 제거했다.
- 모바일390×1000: INTC520px, 한화오션 약450px. 일/주/월 전환·닫기·원위치 복귀를 확인했다. 모달 현재가는 기존 시세를 그대로 사용하며 미국은 달러, 국내는 원으로 표시한다.
- 미국 일봉의 수신 약2년 자료에서 1개월/3개월/6개월/1년/전체 기간 선택을 지원한다. 미국3년/5년 데이터는 수집하지 않았으므로 해당 버튼을 제공하지 않는다. 전체는 수신자료 전체다. 자료 시작일 이전에 빈 구간을 만들지 않는다.
- 미국 기간 버튼이 국내 `/flow-chart` 장기 수집 경로를 호출하지 않게 분리했다. 국내3년/5년 조회는 유지한다. 공통 엔진/보조 모듈 버전을 갱신한다. 수급 흔적은 기존 국내 전용 범위를 확장하지 않았다.
- 시세 산식·검색기 판정·주문/자금/실계좌 설정은 변경하지 않았다.

## 캐시·API

- `us_analysis_cache` 테이블은 그대로 사용하며 payload 캐시 버전3으로 이전 잘못된 집계를 무효화한다. 정상6시간, 빈 metric/financials 응답5분 캐시를 유지한다. 손실기업 등에서 정당하게 미제공인 PER을 임의로 채우거나 해당 필드만으로 반복 재조회하지 않는다.
- 기존 요약 필드는 유지하되 `insider_net_change`는 P 매수수량 − S 매도수량, `insider_transaction_count`는 P/S 건수로 수정한다.
- `summary.insider`: available, from/to, buy/sell shares/counts, other_count, latest_filing, missing_dates, items, coverage.
- `summary.analyst_ratings`: available, status, source, items. 접근 거부는 `access_denied`다. 누락을0건 또는 기관 의견 없음으로 해석하지 않는다.
- 추천 source_url은 종목별 공식 위젯, docs_url은 실제 Finnhub 추천 API 문서다. API 토큰을 링크/로그에 넣지 않는다.
- 추가 프로세스·타이머·DB 스키마·계좌 설정은 없다. 요청은 기존 분석 캐시 만료 시에만 수집한다.

## 검증

- Python: 재무3 + 캐시/ETF9 + 거래 분류·기간·접근 거부·제출대행자 CIK 등7 =19개.
- Node: 미국 기간 선택/국내 API 오호출 방지/자료 범위 보정, 기존 기간·상호작용·작도·표시 호스트 및 메뉴/상세 회귀.
- 배포 전 실제 운영 페이지에 변경 자산만 대입한 Edge 검증: INTC/한화오션 × PC/모바일4조합, 기간/일주월 전환·전체화면 높이·달러/원·복귀, 도넛3구간/55건/정확한 종목 링크. 기관 자료 있음/없음은 합성 자료로 두 경로를 검증했다.
- 국내 공통차트 실제 저장 OHLCV 렌더러12조합 통과. 계좌·주문은 호출하지 않았다.
- 기존 `test_us_orderbook_refresh.py` 모의 객체 문제는 이전 작업에서 기준 커밋에서도 실패를 확인한 별도 이슈로, 이번 통과 수에 포함하지 않는다.

기관별 실제 평가 데이터는 현재 권한 미확보로 검증·제공하지 못한다. 공개되지 않은 SAVE/TipRanks 데이터를 복제하거나 이용 권한을 우회하지 않는다. 최종 운영 배포/API/캡처 결과는 작업 출력 보고서에 남긴다.
