# 코스닥 장중 모니터링 일지

2026-11-27부터 하루 단위로 쌓는 연구 기록이다. 투자 권유·주문과 무관하며 실계좌·운영 검색기와 연결하지 않는다.

## 파일
- `YYYY-MM-DD.md` 사람이 읽는 일지(시장 요약, 규칙 신호와 결과, 당일 상승률 TOP30의 시각별 등락·거래량비)
- `YYYY-MM-DD.json` 같은 내용의 원자료(분석 재사용용)

## 기록 대상(날짜마다 같은 정의)
- 시장: 코스닥 보통주 전체의 상승·하락 수, +5%/+10%/상한가급 종목 수. 마지막 정시 스냅샷 기준.
- 규칙 신호: "수급 들어오기 전 + 강력한 각도". 등락률 2~27% 미만, 최근 5분 상승률 ≥ 2%, 누적 거래량 ÷ 직전 20일 평균 일거래량(거래량비) < 0.2. 30초마다 판정, **09:10~09:11 판정만 검증 대상**, 나머지 시각은 탐색용으로 따로 표시. 신호 이후 30초 간격 가격 경로로 +3%/+5%/−3% 최초 도달 시각, 최고·최저·마지막 관측가를 남김.
- 정시 스냅샷(09:20·09:30·10:00·11:00·13:00·14:00·15:00·15:20·15:35 등): 종목별 현재가·등락률·누적 거래량·거래량비.
- 당일 상승률 TOP30: 마지막 스냅샷 기준 순위, 각 시각의 등락·거래량비, 규칙에 잡혔는지.

## 해석 주의
- 가격은 NAVER 시가총액 JSON(공급자 지연 가능), 30초 간격이라 체결 순서·장중 고저는 근사다. 비용(0.4%)은 일지에 반영하지 않는다.
- 규칙은 과거 60일 분봉에서 사전 고정한 후보이며 아직 채택되지 않았다. 일지가 쌓여야 표본 밖 검증이 된다.
- 첫날(2026-11-27)은 09:05·09:10 전종목 스냅샷이 없다(수집 시작 지연). 규칙 판정 자체는 09:04:47부터 돌았다.

## 생성
`scripts/research/live_angle_watch.py`(규칙 판정), `monitor_snapshots.py`(정시 스냅샷), `monitor_daily_log.py`(일지 생성). Oracle 연구 VM에서 실행한다.
