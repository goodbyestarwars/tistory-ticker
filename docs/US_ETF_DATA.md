# 미국 재무·ETF 데이터 개선 (2026-10-19)

## 적용 내용

- Finnhub의 일시적인 빈 응답을 정상 결과처럼 6시간 보관하던 문제를 수정했다. 기존 캐시 버전을 무효화하고, 기본재무 미확보 결과는 5분만 보관한다. 빈 metric은 1회만 재시도한다. 비정상 숫자(NaN/Infinity)는 누락으로 처리한다. 오류 로그에 인증 URL을 남기지 않는다.
- PBR은 `pb → pbQuarterly → pbAnnual`, ROE는 `roeTTM → roeRfy → roeAnnual`, 순이익률은 `netProfitMarginTTM` 등 실제 필드를 사용한다. 5년 성장률을 단기 성장률로 표시하지 않는다.
- 매출·순이익은 정확한 공시 concept만 선택한다. 비용/주당이익/일부 순이익 항목과 혼동하지 않는다. 최신 보고기간과 공시일을 표시하고, YTD 누적값을 단독분기로 표시하지 않는다.
- PER/PBR/ROE의 원본 필드와 조회일을 제공한다. Finnhub가 비율의 실제 기준일을 제공하지 않아 기준일은 미제공으로 표시한다. 조회일을 기준일로 바꾸지 않는다. AAPL 재조회에서 수치가 복구돼 SEC 보조 수집은 추가하지 않았다.
- 애널리스트 매수·보유·매도 집계는 유지하며 Finnhub와 응답의 기준월을 표시한다. 링크는 **Finnhub 집계 API 문서**다. 개별 애널리스트 원문이나 다른 제공처의 집계 페이지로 오인하게 연결하지 않는다. 집계 누락은 0건으로 오인하지 않게 표시한다.
- 늦게 도착한 이전 종목의 분석 응답이 새 종목 화면을 덮어쓰지 않도록 방어했다.

## ETF: 현재 비활성 데이터 / 활성 UI

기존 증권사 종목목록의 ETF 플래그를 재사용한다. 종목 상세조회마다 전체 목록을 다시 받지 않는다. 미분류는 UNKNOWN이다. ETF 보유명세는 수집하지 않고 `구성종목 데이터 준비 중`과 확인된 운용사 공식 목록 링크를 제공한다. 영문명 검색용 기존 캐시로 운용사를 구분한다. ETF별 심볼 분기는 없다. 미확인 운용사는 임의 링크를 만들지 않는다.

재게시 승인 없는 운용사 보유명세를 다운로드·DB 저장·공개하지 않는다. 운영에는 `US_ETF_LICENSED_SNAPSHOT_DIR`를 설정하지 않는다. 새 공급자 연결 시 기존 서버 작업에서 승인된 스냅샷만 원자 교체하면 된다. 신규 수집 프로세스·타이머·브라우저별 원문 요청은 없다.

### 향후 공급자 계약

`scripts/cloud-vm/us_etf_holdings.py`는 공통 공급자 경계다. 환경변수 경로의 `license.json`을 **먼저** 확인한다. `public_display_allowed=true`, `storage_allowed=true`, 실제 계약을 가리키는 비공개 `license_reference`, `expires_on`, HTTPS `source_url`, `provider`, 선택 `max_age_days`(기본95일)가 필요하다. 단순 설정값이 계약상의 권리를 만들어 주지 않는다. 실제 공개 웹사이트 표시·서버 보관 허용을 계약으로 확인한 뒤 운영자가 설정한다. 비밀 계약 내용을 API로 반환하지 않는다.

승인 전에는 보유명세 파일도 읽지 않는다. 승인 후에만 `<SYMBOL>.json`의 `symbol`, ISO `as_of`, `holdings`를 읽는다. 각 행은 `name`, `ticker`(없으면 null), `weight_percent`, `country`, `kind`(equity/cash/derivative/other), `basis`(holding_value/economic_exposure)를 갖는다. 합성 데이터로 계약만 검증했다. 실제 공급자 어댑터/계약은 아직 연결하지 않았다.

누락·만료·오래된 명세·미래 기준일·잘못된 숫자·스키마 오류는 준비 중으로 처리한다. 최대2MB/20,000행, 최근4종목 메모리 캐시(1시간), mtime 변경 즉시 재검증. 권한 파일은 매번 확인하므로 허가 철회·만료 시 기존 캐시도 공개하지 않는다. 비중 내림차순으로 표시하며 현물과 실질노출은 합산/정규화하지 않는다. UI는 상위20개와 전체 보기, 국가·파생상품 구분·기준일·출처를 지원한다. 모든 신규 링크는 밑줄 없이 색상/화살표/키보드 포커스를 유지한다.

## 배포

JS/CSS는 GitHub Pages, Python은 기존 VM 자동배포 경로. 사용자 지시로 테스트된 일반 기능을 master에 반영한다. ETF 보유명세 공급자는 비활성 유지한다. 시세·차트 엔진·검색기·주문/자금/실계좌 설정 변경 없음. 최종 운영 커밋/API/화면 확인 결과는 출력 보고서에 기록한다.
