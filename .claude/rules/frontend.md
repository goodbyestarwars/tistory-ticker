# 프론트엔드 규칙

- Tistory 치환 태그 `[##_..._##]`와 `<s_xxx>` 구조를 보존한다.
- 기존 전역 객체와 DOM 선택자 계약을 확인한 뒤 수정한다.
- 정적 자산 URL 때문에 파일명 버저닝을 하지 않는다.
- 데이터 파일은 `window.XXX = {...}` 형식의 `.js`를 사용한다.
- PC와 모바일 레이아웃을 함께 확인한다.
- 필요할 때만 `docs/UI_GUIDE.md`를 읽는다.
