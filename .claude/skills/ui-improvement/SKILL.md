# UI 개선

1. 대상 화면과 유지할 기능을 확인한다.
2. 관련 HTML, JS, CSS와 이벤트 연결을 함께 읽는다.
3. 필요할 때만 `docs/UI_GUIDE.md`를 읽는다.
4. 정보 위계와 PC 레이아웃을 먼저 정리한다.
5. 모바일 스크롤, 줄바꿈, 터치 영역을 보완한다.
6. 상승·하락 등 의미색을 보존한다.
7. PC·모바일에서 기능과 레이아웃을 검증한다.
8. 변경 파일과 시각적 영향 범위를 요약한다.
