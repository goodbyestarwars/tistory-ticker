# 기능 개발

1. 요청 범위와 완료 조건을 정리한다.
2. 관련 파일과 호출 흐름만 검색한다.
3. 구조는 `ARCHITECTURE.md`, API는 `API_REFERENCE.md`의 관련 부분만 읽는다.
4. 기존 패턴을 재사용하는 최소 변경안을 세운다.
5. 구현하고 관련 검증을 실행한다.
6. PC·모바일, 캐시, 오류 처리, 배포 경로를 확인한다.
7. 변경 파일, 검증 결과, 수동 배포 항목을 요약한다.

범위 밖 리팩터링이나 기존 기능 삭제는 하지 않는다.
