# 오류 수정

1. 증상, 재현 조건, 기대 결과를 확인한다.
2. 관련 파일과 최근 변경만 조사한다.
3. 입력부터 출력까지 실패 지점을 좁힌다.
4. 원인과 수정 범위를 명확히 한다.
5. 최소 범위로 수정한다.
6. 정상 사례와 회귀 여부를 검증한다.
7. 원인, 변경 파일, 검증 결과, 남은 위험을 요약한다.

API 필드명, 단위, 시장 범위를 추측하지 않는다.
